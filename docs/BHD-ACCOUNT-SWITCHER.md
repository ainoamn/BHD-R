# مواصفة تبديل حساب BHD — عزل + أسلوب جوجل

> **الحالة:** معتمدة. انسخ هذا الملف إلى `docs/BHD-ACCOUNT-SWITCHER.md` في كل منتج ونفّذه.  
> **المصدر:** [ainoamn/ONE-BHD](https://github.com/ainoamn/ONE-BHD) — `docs/BHD-ACCOUNT-SWITCHER.md`  
> **التاريخ:** 20 أكتوبر 2026  
> **الهوية:** `https://id.bhd-om.com`  
> **انسخ معه:** `BhdAppSwitcher.tsx` · `BhdSilentSso.tsx` · `lib/identity/client.ts` · `lib/bhd/apps.ts`

حساب نشط واحد في المتصفح (مثل جوجل). كل مواقع BHD تعرض **بيانات هذا الحساب فقط**. بقية الحسابات تبقى محفوظة في القائمة بلا خروج، والتبديل يغيّر البيانات كلها.

---

## 1. شكل البطاقة

```
┌──────────────────────────────────┐
│  (صورة)  email@domain     G     │  ← بريد + شارة المصدر بجانب البريد
│          إدارة الحساب           │     الصورة دائرية نظيفة بلا شعار داخلها
├──────────────────────────────────┤
│  (صورة)  other@domain     f     │
│  (+)     إضافة حساب آخر         │
├──────────────────────────────────┤
│  خروج من هذا الحساب             │
│  خروج من كل الحسابات            │
└──────────────────────────────────┘
```

| عنصر        | القاعدة                                                                         |
| ----------- | ------------------------------------------------------------------------------- |
| الصورة      | دائرة 40px (56px للنَشط). صورة الحساب فقط. **ممنوع** وضع شعار/حرف G داخل الصورة |
| النص        | **البريد** (`dir="ltr"`). وإلا اسم المستخدم ثم الهاتف                           |
| شارة المصدر | بجانب البريد لا فوق الصورة: `G` جوجل · `f` فيسبوك · `WA` واتساب · `●` عادي      |
| إضافة       | صف `+` فقط — هذا المسار الوحيد لـ `/login?add=1`                                |

---

## 2. الحساب النشط يعزل البيانات (إلزامي)

1. القائمة من `GET https://id.bhd-om.com/api/auth/me` مع `credentials: "include"` **مباشرة إلى الهوية** (لا تطلب `/api/auth/me` المحلي ثم تتبع 308).
2. التبديل: `POST https://id.bhd-om.com/api/auth/switch` `{ "sub": "<id>" }`.
3. بعد نجاح التبديل **أعد تحميل الصفحة الحالية ببيانات الحساب الجديد**:
   - على الهوية: `location.assign(path)` لنفس المسار — ليس `/login`.
   - على المنتج: `location.assign(/api/auth/bhd/start?returnTo=path)` لربط جلسة المنتج بـ `sub` الجديد.
4. ممنوع الإبقاء على بيانات الحساب السابق في الذاكرة أو في كوكي المنتج.
5. ممنوع فتح `/login?add=1` عند التبديل. `add=1` فقط لزر «إضافة حساب آخر».
6. إن كان المستخدم مسجّلاً وزار `/login` بلا `add=1`: حوّل إلى `/account` أو `next` (SSO صامت). لا تطالب بدخول جديد ولا تخرج الحسابات الأخرى.

---

## 3. فتح موقع آخر برابط (بدون أيقونة التطبيقات)

مثل جوجل: الرابط المباشر يستخدم الحساب النشط على الهوية.

انسخ `BhdSilentSso` إلى تخطيط المنتج:

- إن وُجد مستخدم على `id.bhd-om.com/api/auth/me` ولم تطابق جلسة المنتج `user.id` → `302` صامت إلى `/api/auth/bhd/start?returnTo=المسار الحالي`.
- لا شاشة دخول، لا `add=1`، لا طلب خروج، لا إجبار على تبديل الحساب في الصفحة الثانية.
- إن طابقت الجلسة: اعرض الصفحة فوراً.

عدة حسابات تبقى في القائمة في الوقت نفسه. الصفحة تعرض **الحساب النشط فقط**. التبديل من الرأس يغيّر كل المواقع إلى ذلك الحساب.

---

## 4. مسارات النسخ

| الملف                                   | أين                                                         |
| --------------------------------------- | ----------------------------------------------------------- |
| `app/components/bhd/BhdAppSwitcher.tsx` | الرأس                                                       |
| `app/components/bhd/BhdSilentSso.tsx`   | `layout` بجانب الرأس                                        |
| `app/lib/identity/client.ts`            | `identityFetch` / `applyAccountIsolation` / `addAccountUrl` |
| `app/lib/bhd/apps.ts`                   | الكتالوج                                                    |

`connect-src` في CSP يجب أن يشمل `https://id.bhd-om.com`.

إضافة حساب من منتج:

```
https://id.bhd-om.com/login?add=1&next=/auth/continue?to=<رابط الصفحة الحالية>
```

بعد الدخول يعود عبر `start` إلى نفس الصفحة بالحساب الجديد.

---

## 5. اختبار قبول

1. حسابان في القائمة. التبديل يغيّر البريد والصورة **وكل بيانات الصفحة** إلى الحساب الجديد.
2. التبديل لا يفتح `/login?add=1`.
3. `/login` وجلسة قائمة بلا `add=1` → لا نموذج دخول.
4. فتح `wazen.bhd-om.com/...` من شريط العنوان وجلسة هوية قائمة → دخول صامت بالحساب النشط.
5. الصورة بلا شعار داخلها. الشارة بجانب البريد.
6. إضافة حساب تبقي الحسابات السابقة في القائمة.

انسخ هذا الملف كما هو إلى كل مستودع BHD.
