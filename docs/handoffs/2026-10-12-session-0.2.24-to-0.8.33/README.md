## على الجهاز الآخر

```bash
git clone https://github.com/ainoamn/BHD-R.git   # أو: git pull origin main
cd BHD-R
pnpm install --frozen-lockfile                     # Node >= 22، وpnpm 10.14
pnpm --filter @bhd-r/authz --filter @bhd-r/db run build
```

- **المتغيّرات:** الأسرار ليست في git. انسخ `.env.example` إلى `.env` ثم املأه، أو اسحبها من Vercel:
  ```bash
  vercel login
  vercel link
  vercel env pull apps/web/.env.local
  ```
  Vercel CLI على هذا الجهاز غير مسجَّل الدخول.
- **الفحوص:**
  - فحص الأنواع من جذر المستودع: `npx tsc -p apps/web --noEmit`.
  - من داخل `apps/web`: `npx eslint <files>` و`npx vitest run`.
- **النشر:** `git push origin main` يكفي. Vercel يبني `apps/web` تلقائياً، وRender يبني `apps/api`. أما المهام الدورية كل 5 و10 دقائق فهي في GitHub Actions (`.github/workflows/scheduled-pings.yml`) منذ 2026-10-06.
- **مسار البناء:** Cloudflare Workers ليس مسار النشر، وتفصيل ذلك في [`implementation/CLOUDFLARE-NOT-DEPLOY-PATH-AR.md`](../../implementation/CLOUDFLARE-NOT-DEPLOY-PATH-AR.md).
