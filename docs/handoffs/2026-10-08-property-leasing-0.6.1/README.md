## اختبار القبول على الإنتاج

- [ ] قسم الحجوزات: «اعتماد الحجز» لـ `ST-6C2A8BBC` ← الحجز «مؤكّد»، عقد «معتمد وموقّع» في العقود، وإيجار في التأجير.
