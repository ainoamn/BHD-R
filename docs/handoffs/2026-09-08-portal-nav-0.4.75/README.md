## ما تغيّر
- تسجيل شجرة الصفحة الحقيقية داخل الغلاف (`PortalPage` / `persistentPortalPage`).
- إبقاء لوحة التحكم، العقارات، العقود، المعاينات، والإقامات مركّبة عند الرجوع (بدون حد 12 صفحة).

- حفظ/تعديل العقار بتنقل عميل بدل إعادة تحميل المستند.

## تحقق بعد النشر
1. `/ar/owner` — انتظر بضع ثوانٍ ثم تنقّل بين الأقسام.
2. مسودة إضافة عقار → زيارة أكثر من 12 قسماً → الرجوع (تبقى الحقول).
3. تعديل عقار وحفظه — بدون إعادة تحميل كاملة.
4. تفاصيل حجزين يوميين + زر الرجوع.
