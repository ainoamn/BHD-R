# ADR-004: عزل المؤسسات وResource Grants

- **الحالة:** Proposed for phase-zero gate
- **التاريخ:** 23 أغسطس 2026

## القرار

- كل مؤسسة Tenant مستقل.
- كل صف تشغيلي يحمل `tenant_id` وتطبق RLS.
- العضوية داخل مؤسسة المالك/المطور.
- المستأجر لا يدخل مؤسسة المالك؛ يحصل على ResourceGrant محدد.
- Policy Guard عالمي fail-closed بعد المصادقة والسياق.

## الأسباب

يفصل بيانات العملاء ويمنع أن يمنح عقد واحد المستأجر رؤية عقارات أو تقارير المؤسسة. كما يسمح للشخص بسياقات متعددة دون خلطها.

## النتائج

- جميع Repositories تحتاج Tenant context.
- التقارير والبحث والتصدير والملفات تخضع للاختبارات نفسها.
- Service accounts لا تستخدم RLS bypass داخل Web request.
