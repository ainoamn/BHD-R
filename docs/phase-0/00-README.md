## القرارات المطلوبة لإغلاق البوابة

1. اعتماد `r.bhd-om.com` كنطاق رسمي و`bhd-r` كـOIDC client id.
2. تأكيد أن إضافة العقار في V1 تبدأ من إدارة المنصة، مع إمكانية منح Self-onboarding للمالك/المطور كباقة لاحقة.
3. اعتماد اسم مستخدم + رابط/رمز تفعيل أحادي الاستخدام بدلاً من إرسال كلمة مرور دائمة.
4. اعتماد إبقاء رابط الوحدة غير المتاحة بصفحة مختصرة `noindex` بدلاً من 404 افتراضياً.
5. تحديد ما إذا كانت دفعات الإيجار داخل V1 أم تسجيل/مطابقة دفعات فقط في أول Pilot.
6. اختيار مستوى التوقيع القانوني ومزود التوقيع/OTP بعد مراجعة قانونية.
7. تحديد المؤسسات والبيانات التي ستدخل Pilot والترحيل الأول.

## نتيجة البوابة

عند اعتماد القرارات السبعة تصبح ADRs المقترحة `Accepted`، ثم تبدأ المرحلة 1: إنشاء Monorepo والأساس المشترك فقط.
