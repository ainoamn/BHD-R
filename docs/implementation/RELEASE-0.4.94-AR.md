# الإصدار 0.4.94 — صفحة حجز الإقامة اليومية

## ما الذي تغيّر

### تصميم الصفحة `/stays/[slug]/book`

- نفس تخطيط صفحة حجز الإيجار/الشراء: صورة جانبية أصغر ومساحة أكبر لنموذج البيانات (`stays-book-shell--wide-form`).
- نص جديد:
  - «احجز إقامتك القادمة — بدفع آمن عبر BHD R».
  - «أصبح حجز إقامتك أسهل من أي وقت مضى، في أربع خطوات بسيطة:»
    1. اختيار تواريخ الإقامة ونوعها.
    2. إدخال بياناتك.
    3. مراجعة الحجز والموافقة على الشروط والأحكام.
    4. الدفع بأمان وتوقيع العقد إلكترونيًا.
  - «ابدأ إجراءات الحجز الآن» مع سهم متحرك يشير إلى النموذج.
- زر تبديل اللغة (العربية/English) يحافظ على التواريخ والوحدة وعدد الضيوف ونوع الإقامة.

### خطوة «بياناتك»: الحجز لنفسي أو لشخص آخر

- للمستخدم المسجّل: سؤال «هل الحجز لك؟» مع «نعم، الحجز لي» / «لا، لشخص آخر».
  - «لي»: تُعبّأ البيانات من الملف، ويمكن حفظ رقم الهاتف في الملف.
  - «لشخص آخر»: اختيار من «الأشخاص المحفوظين في ملفك» أو «+ شخص جديد»، مع خيار حفظ الشخص أو تحديث بياناته.
- الزائر غير المسجّل: نموذج الضيف كما كان.
- المراجعة تعرض صف «الحجز لـ».

### الخادم

- `createStayBookingSchema` يقبل `bookingFor` اختياريًا (`self` / `other`).
- لقطة الحجز (`pricingSnapshotJson`) تحفظ `bookingFor` و`bookedBy` (المستخدم المسجّل الذي أجرى الحجز).
- عقد الإقامة يعرض «تم الحجز بواسطة» عندما يكون الحجز لشخص آخر.
- مسار جديد `POST /api/public/booking-contacts` (جلسة حيّة + CSRF + حد للطلبات) لحفظ جهة الاتصال بعد إنشاء الحجز؛ فشل الحفظ لا يوقف الحجز.
