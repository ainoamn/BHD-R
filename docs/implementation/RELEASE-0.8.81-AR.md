# الإصدار 0.8.81 — إدخال قيد، صرف/دخل، مشتريات/مبيعات، وشيكات

**التاريخ:** 2026-10-18

## المطلوب

1. زر «إضافة قيد» يفتح نموذج إدخال القيد (لا نموذج دائم في الصفحة).
2. مكان لإدخال المشتريات والمبيعات مع قيودها.
3. عند الصرف أو الدخل: اختيار مبنى/وحدة من قائمة تُجلب تلقائياً.
4. استيراد الشيكات وعرض شيكات المستأجرين مع الحالة وتواريخ الاستحقاق.

## الحل

- نموذج قيد يومية في نافذة منفصلة عبر زر «＋ إضافة قيد».
- تبويب **صرف ودخل** مع نوع صرف/دخل وربط مبنى/وحدة.
- تبويب **مشتريات ومبيعات** يرحّل قيوداً (5600 / 4400) مع طريقة دفع/تحصيل وربط عقاري.
- تبويب **الشيكات**: قائمة بحالة الشيك والاستحقاق + استيراد CSV.
- حسابان جديدان في الدليل: `5600` مشتريات و`4400` مبيعات (يُضافان عند المزامنة/التهيئة).

لا ترحيل قاعدة بيانات.
