# معالج إضافة عقار — BHD R

**المسار:** `/{ar|en}/{owner|developer}/properties/new`  
**المكوّن:** `apps/web/src/components/property-wizard.tsx`

## المراحل (مرقّمة 1–6)

| # | المحتوى |
|---|--------|
| 1 | الأساسيات + موقع عُمان (محافظة → ولاية → قرية) |
| 2 | الوحدات + توضيح «عرض عند التوفر» |
| 3 | التشغيل والمرافق (قائمة موسّعة + مرفق مخصص) |
| 4 | الملكية + مرفقات وثائق (أيقونات + معاينة) |
| 5 | الصور + اختيار صورة الغلاف |
| 6 | وصف ذكي قابل للتعديل/الترجمة + معاينة بطاقة الصفحة الرئيسية |

- الضغط على رقم مرحلة **سابقة** يرجع إليها.
- الانتقال لمرحلة لاحقة ممنوع حتى تكتمل الحالية (تحقق + قائمة نواقص).

## التحقق المرئي

- الحقول الإلزامية الفارغة: إطار أحمر (`.field--missing`)
- بعد التعبئة: إطار أخضر (`.field--ok`)
- عند «التالي» مع نقص: تنبيه + قائمة الحقول

## موقع عُمان

البيانات من `apps/web/src/lib/oman-locations.ts` (منسوخة من [bhd-om](https://github.com/ainoamn/bhd-om)).

## الوصف والترجمة

- توليد نص احترافي من البيانات: `apps/web/src/lib/property-listing-copy.ts`
- مساعدة ترجمة فورية لعبارات شائعة AR↔EN (قابلة للتوسيع لاحقاً بـ LLM)

## صورة الغلاف

تُرفع أولاً بـ `position: 0` عبر `POST /v1/media/:id/complete` (`position` اختياري). الغلاف = أصغر `unit_media.position`.

## الترقيم المتسلسل

- عقارات: `BHD-{year}-PRP-{R|S|I}-{NNNN}` عند الإنشاء  
  جداول: `properties.serial_number` + `property_sequences` (هجرة `0012_property_serials.sql`)
- عقود: موجودة مسبقاً `CTR-{year}-{NNNNNN}` عبر `contract_sequences`
- مستخدمون: نفس نمط bhd-om `USR-…` يُخطَّط لاحقاً عند توحيد الترقيم عبر المنصة

## أين تظهر الوحدة للعامة؟

عند تفعيل «عرض الوحدة عند توفرها»: الصفحة الرئيسية `/` وصفحة `/properties` للزوّار بعد أن تصبح متاحة ومنشورة — وليس داخل بوابة المالك فقط.

## الهجرة

```bash
pnpm db:migrate   # يطبّق 0012_property_serials
```
