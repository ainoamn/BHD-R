# الإصدار 0.3.1 — تنقل سلس مثل Qootk (بدون شاشة بيضاء)

**التاريخ:** 2026-08-31

## المشكلة

عند التنقل أول مرة تظهر شاشة بيضاء 2–5 ثوانٍ لأن Next.js كان يفريغ محتوى الصفحة (`loading.tsx`) ويعيد تحميل القسم من الصفر.

## الاتفاق

تصميم مشابه لـ [qootk.com](https://qootk.com/): انتقال سلس كأن الصفحات محمّلة مسبقاً والتنقل داخل نفس الصفحة.

## الإصلاح

1. **`PortalMainSlot`**: أقسام التشغيل تُعرض داخل هيكل البوابة الثابت (لا تُمسَح عند تغيير الرابط).
2. **نقرة تفاؤلية**: عند الضغط على عنصر القائمة يتبدل القسم فوراً من الذاكرة قبل اكتمال مسار Next.
3. **لا شاشة إقلاع**: المحتوى يُرسم فوراً من الكاش أو هيكل فارغ — بلا «جاري التحميل» الأبيض.
4. **حذف `owner/loading.tsx` و`developer/loading.tsx`**: كانا سبب إفراغ الشاشة أثناء الانتظار.
5. **التدفئة الخلفية** تبدأ فوراً عند فتح البوابة.

## تحقق

حدّث بقوة → افتح بوابة المالك → انتظر ثانية أو اثنتين → تنقّل بين الاعتمادات/العقارات/الفواتير. يفترض تبديل فوري بدون شاشة بيضاء.
