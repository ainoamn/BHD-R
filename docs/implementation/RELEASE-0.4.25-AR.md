# الإصدار 0.4.25 — بحث وحجز شبيه Booking.com

**التاريخ:** 2026-09-02

## الملخص

- **الصفحة الرئيسية:** شريط بحث أفقي (وجهة · تواريخ · ضيوف · بحث) مع تبويب «إقامة يومية» افتراضي.
- **نتائج `/stays`:** شريط بحث ثابت + عدد النتائج للتواريخ المختارة.
- **الحجز:** معالج 4 خطوات (الإقامة → بياناتك → المراجعة → الدفع).
- **التأكيد:** صفحة `/stays/booking/confirmed?ref=…` بعد الدفع.

## التدفق

1. الرئيسية → اختر تواريخ واضغط بحث
2. `/ar/stays` → عقارات متاحة فقط لتلك التواريخ
3. اختر عقاراً → `/ar/stays/{slug}`
4. أكمل الخطوات → ادفع → صفحة التأكيد
