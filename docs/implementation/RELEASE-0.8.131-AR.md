# الإصدار 0.8.131 — إلزام مسؤول المعاينة قبل تأكيد الموعد

**التاريخ:** 2026-10-19

## المطلوب

لا يمكن للمالك أو من ينوب عنه تأكيد موعد المعاينة وإشعار العميل ما لم يُحدَّد أولاً حارس المبنى / المسؤول عن المعاينة من صفحة العقار.

## الحل

1. عمود `properties.viewing_contact_user_id` (ترحيل `0044_property_viewing_contact.sql`).
2. بطاقة «مسؤول المعاينة / حارس المبنى» في صفحة إدارة العقار لاختيار عضو فريق ميداني وحفظه.
3. واجهة طلب المعاينة تعطّل زر «تأكيد الموعد وإشعار العميل» وتعرض تنبيهاً مع رابط لصفحة العقار عندما لا يوجد مسؤول.
4. الخادم يرفض `schedule` بـ `viewing_contact_required` إن لم يُعيَّن المسؤول؛ عند التأكيد يُسند الطلب إليه ويُشعَر بالبريد مع العميل.
