## ماذا أُضيف

| قدرة | أين |
| --- | --- |
| تفاصيل الحركة | زر **التفاصيل** → نافذة (قيد بأسطر الحسابات أو تحصيل إقامة) |
| طباعة تفاصيل | من النافذة |
| طباعة كشف الفترة | شريط الأدوات حسب التصفية الحالية |
| تصدير CSV | نفس التصفية |
| حسابي | رابط للكشوفات/الأستاذ المفصّل |

## لماذا لا ننسخ bhd-om؟

[bhd-om](https://github.com/ainoamn/bhd-om) ليس مصدر محاسبة SaaS جاهز للنسخ داخل BHD-R. القرار D-207: عقارات = سجل تشغيلي؛ Hisaby = GL وكشوفات ضريبية كاملة.

## اختبار

1. افتح `/ar/owner/accounting`
2. اضغط **التفاصيل** على صف إقامة أو قيد
3. **طباعة التفاصيل** / **طباعة الكشف** / **تصدير CSV**
