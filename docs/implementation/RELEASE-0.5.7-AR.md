# الإصدار 0.5.7 — فصل «عرض العقارات» عن «إدارة العقارات»

**التاريخ:** 2026-10-08
**الصفحات:** `/[locale]/owner/properties` و`/[locale]/developer/properties` والشريط الجانبي للبوابة

## المشكلة

صفحة المحفظة العقارية كانت تجمع العرض والإدارة معاً: كل صف فيه زرّا «عرض العقار» و«إدارة العقار» (وللوحدات «عرض الوحدة» و«إدارة الوحدة»)، فازدحمت القائمة ولم يكن واضحاً أين يتصفّح المالك وأين يدير.

## التصميم الجديد

### الشريط الجانبي

- «العقارات» أصبح قائمة منسدلة بدل رابط مباشر. الضغط عليه يفتحها أو يغلقها.
- تحتوي خيارين:
  - **عرض العقارات** ← `/{portal}/properties`
  - **إدارة العقارات** ← `/{portal}/properties?mode=manage`
- تكون القائمة مفتوحة تلقائياً عند وجودك داخل أي صفحة عقارات، ويتميّز الخيار الحالي.
- صفحات العقار الفردي (`/properties/[id]` والتعديل والشروط) تُحسب ضمن «إدارة العقارات»، ومعالج الإضافة (`/properties/new`) ضمن «عرض العقارات».

### صفحة «عرض العقارات»

- نفس القائمة (الصورة، الرقم، الاسم، الموقع، النوع، القنوات، الوحدات، الحالة).
- بلا عمود «الإجراء التالي» وبلا أزرار في الصفوف، على الكمبيوتر وبطاقات الجوال.
- زرّا «الأرشيف» و«＋ إضافة عقار متكامل» أعلى الصفحة بقيا كما هما.

### صفحة «إدارة العقارات»

- العنوان «إدارة العقارات» وتحته «اختر العقار أو الوحدة التي تريد إدارتها.»
- عمود «الإدارة» فيه زر واحد لكل صف: «إدارة العقار»، أو «إدارة الوحدة» لوحدات المباني.
- حُذف زر «عرض العقار» (الإعلان العام) لأن صفحة إدارة العقار فيها أصلاً زر «عرض للجمهور».
- سهم الرجوع في صفحة إدارة العقار يعيد الآن إلى «إدارة العقارات».

### لماذا رابط واحد مع `?mode=manage`

لوحات العمليات محفوظة في الذاكرة لكل قسم (`PortalMainSlot`)، فاستخدام نفس القسم `properties` مع معامل `mode` يجعل الانتقال بين الصفحتين فورياً دون إعادة تحميل البيانات.
