# واجهة بوابات التحكم (Portal Chrome) — BHD R

**الحالة:** مطبّق على `owner` / `developer` / `tenant` / `platform` (الإدارة)  
**المسار الحي:** `/{ar|en}/{portal}/…` مثل `/ar/owner`

## الهدف

توحيد تجربة التحكم مع هوية حساب BHD ووازن والبوابة الرئيسية:

- شريط علوي ثابت يظهر **بيانات المستخدم** (الاسم، الدور، البريد/المعرّف)
- تبديل لغة عربي ↔ إنجليزي من الهيدر
- مبدّل تطبيقات BHD (نفس نمط الواجهة العامة)
- قائمة جانبية مجمّعة حسب الوظيفة، متجاوبة على الجوال

## المكوّنات

| ملف | دور |
|-----|-----|
| `apps/web/src/components/portal-shell.tsx` | غلاف البوابة + `requirePortal` |
| `apps/web/src/components/portal-header.tsx` | الهيدر: علامة، لغة، مستخدم، App Switcher |
| `apps/web/src/components/portal-nav.tsx` | قائمة مجمّعة + درج الجوال |
| `apps/web/src/app/globals.css` | أنماط `.portal-layout` / `.portal-chrome` / `.portal-sidebar` |
| `apps/web/src/app/portal-adaptive.css` | طبقة قياس موحّدة (أيقونات/نص/حقول) حسب العرض — **0.2.59** |
| `packages/i18n/src/index.ts` | مفاتيح `Portal.group*` + عناوين البوابات |

كل مسارات `owner|developer|tenant|platform` تستخدم `PortalShell` فقط — لا يوجد قالب منفصل لكل دور.

## التخطيط

```
┌──────── portal-chrome (full width, sticky) ────────┐
│ علم عُمان · BHD R · اسم البوابة · لغة · مستخدم · تطبيقات │
├──────── sidebar ────────┬──────── portal-main ─────┤
│ مجموعات القائمة         │ نظرة عامة / ops console  │
└─────────────────────────┴──────────────────────────┘
```

على العرض ≤960px: الشريط الجانبي يصبح درجًا منزلقًا (RTL-aware)، وزر ☰ في الهيدر يفتحه/يغلقه.

## التجاوب (Responsive)

| العرض | السلوك |
|------|--------|
| >1100px | عمود قائمة 17rem + نص المستخدم كامل |
| 961–1100px | قائمة أضيق (15.25rem) + تقليص عرض بطاقة المستخدم |
| ≤960px | تخطيط عمود واحد للمحتوى؛ قائمة درج مخفية خارج الشاشة؛ زر ☰؛ إخفاء عناوين الهيدر/بطاقة المستخدم/شبكة التطبيقات؛ محفظة العقارات كبطاقات (انظر [`PORTAL-ADAPTIVE-PROPERTIES-AR.md`](./PORTAL-ADAPTIVE-PROPERTIES-AR.md)) |
| ≤520px | عنوان بوابة مختصر؛ شعار وأيقونات أصغر عبر `--portal-*` |

### إصلاح الدرج (0.2.23)

سبب بقاء القائمة ظاهرة على الجوال بعد 0.2.22:

1. أنيميشن `portal-side-in` يضبط `transform: none` مع `fill-mode: both` فيتغلب على إزاحة الإخفاء.
2. قاعدة `@media (max-width: 1100px)` كانت تعيد `grid-template-columns: 15.25rem …` حتى تحت نقطة الدرج.

العلاج: تعطيل أنيميشن الدخول تحت 960px، فصل تضييق العمود إلى `961–1100px` فقط، وإعادة تأكيد تخطيط الدرج؛ `PortalNav` يستخدم `matchMedia` و`inert` عندما يكون الدرج مغلقاً.

اختبارات يدوية مقترحة:

1. iPhone SE / 375px — القائمة مخفية عند التحميل؛ فتح/إغلاق ☰ والخلفية وEscape؛ تبديل اللغة
2. Tablet 768–960 — درج + محتوى بعرض كامل
3. Desktop 1280+ — شريط جانبي ظاهر دائمًا وقابل للنقر
4. `dir=rtl` و`dir=ltr` لانزلاق الدرج


## اللغات

- المسار دائمًا مسبوق بـ `ar` أو `en` (`localePrefix: always`)
- رابط اللغة يحافظ على نفس `pathname` ويبدّل `locale`
- تسميات القائمة عبر `next-intl` (`Common.*` و`Portal.*`)
