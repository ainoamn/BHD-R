# الإصدار 0.2.95 — إصلاح حفظ تعديل العقار (CSRF على Next)

**التاريخ:** 2026-08-31

## السبب

حفظ التعديل كان يرسل كوكي CSRF صادرة من Nest/Render، بينما مسار Neon على Vercel يتحقق بـ `CSRF_SECRET` المحلي — فيُرفض الطلب (أو يفشل جلب الرمز عبر Nest) ويظهر خطأ مضلّل عن `DATABASE_URL`.

## الإصلاح

1. مسار جديد `GET /api/auth/csrf` يصدر الرمز على Vercel مباشرة.
2. المتصفح يطلب هذا المسار قبل الحفظ (بدون الاعتماد على Nest).
3. عند 403 يُعاد إصدار الرمز ويُعاد الطلب مرة واحدة.
4. رسائل خطأ أوضح.

## ماذا تفعل الآن

1. **تحديث قوي للصفحة** (Ctrl+Shift+R) على صفحة التعديل.
2. احفظ العقار مجدداً.
