# الإصدار 0.3.5 — تثبيت تنقل SPA (Qootk) ونشر التحسينات المحلية

**التاريخ:** 2026-08-31

## السياق

قياسات المتصفح أكدت أن الخادم يرد بسرعة (~0.35ث) بينما بطء 20–160ث جاء من عاصفة prefetch وإعادة بناء الصفحة. إصلاحات إضافية بقيت محلية بعد 0.3.3/0.3.4 — هذا الإصدار ينشرها.

## ما يُنشر

1. الإبقاء على آخر **8** أقسام مركّبة في الخلفية (بحث/فلاتر/نماذج).
2. تبديل تفاؤلي فوري عند النقرة قبل اكتمال Next.
3. Prefetch لهياكل غير تشغيلية فقط + تدفئة بيانات بتوازي محدود (2).
4. إصلاح `/api/warm` (لا JSON مع 204).
5. روابط العقارات/العقود/مساحة BHD بتنقل عميل.
6. اختبار E2E يمنع رجوع إعادة تحميل المستند.

## تحقق محلي سابق

- ظهور القسم ~145–486ms  
- تحديث المسار ~133–213ms  
- TypeScript / Unit / Build / E2E ناجحة
