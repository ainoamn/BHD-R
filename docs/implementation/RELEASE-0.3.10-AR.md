# الإصدار 0.3.10 — جلسة التسويق متسقة مع البوابة

**التاريخ:** 2026-08-31  
**الصفحات:** https://r.bhd-om.com/ar · https://r.bhd-om.com/ar/owner

## المشكلة

المستخدم مسجّل في `/ar/owner` بينما الصفحة الرئيسية `/ar` تعرض «الدخول الموحد» كأنه غير مسجّل.

## السبب

ترويسة التسويق كانت تستعلم Nest عبر `/v1/me`. عند نوم Render أو فشل البروكسي تُعامل الجلسة كمجهولة، رغم أن كوكي المنتج `bhd_r_session` صالح والبوابة تقرأه عبر Neon.

## الإصلاح

1. `GET /api/auth/me` — يقرأ الجلسة محلياً عبر `getShellViewer`.
2. `SiteHeader` يستخدم `/api/auth/me` بدل `/v1/me`.
3. أزرار الصفحة الرئيسية تظهر «مساحتي» عند وجود جلسة.

## تحقق

1. سجّل دخولاً وافتح `/ar/owner`.
2. افتح `/ar` — يجب أن يظهر «مساحتي» / مبدّل التطبيقات بدل «الدخول الموحد».
3. `/api/auth/me` يعيد `200` مع بيانات المستخدم عند وجود الكوكي.
