# الإصدار 0.8.136.241 — توحيد كروم صفحات بوابة المالك

**التاريخ:** 2026-11-18  
**النطاق:** كل صفحات `/[locale]/owner/*` (وليس الرئيسية فقط)  
**المعاينة:** https://r.bhd-om.com/ar/owner

## الهدف

بعد 0.8.136.240 أصبحت الرئيسية احترافية بينما بقيت الصفحات الداخلية بشريط علوي داكن/زجاجي. هذا الإصدار يوحّد المظهر التنفيذي الأبيض عبر الطبقة المشتركة لكل الأقسام في القائمة الجانبية.

## الأقسام المشمولة

- الأساسي: لوحة التحكم (سابقاً) + العقارات + الأطراف
- المعاملات: الطلبات، طلبات المستأجرين، الحجوزات والمعاينات، التأجير، البيع، عقود الشراء، الشروط
- الإقامات اليومية: لوحة الإقامات، التقويم، الأسعار والعروض
- المالية: الفواتير، المدفوعات، المحاسبة، المصروفات
- التشغيل: الصيانة، أوامر العمل، المهام، المحاماة، الاعتمادات
- المنظمة: التقارير، الضبط، الفريق

## ما تغيّر

- `ops-header` و`portal-topbar`: من تدرج داكن إلى بطاقة بيضاء بحدود وظل خفيف (مثل الرئيسية).
- `ops-panel` + شريط الأدوات + الجداول: سطح أبيض موحّد بدون زجاج داكن.
- بطاقات المقاييس: بلاط أبيض؛ البلاطة المميزة فاتحة بدل خلفية داكنة.
- أزرار بزوايا `0.75rem` بدل حبوب كاملة في معظم السياق.
- رأس جداول أهدأ (`#f7f9f8`) بدل تدرج أخضر كثيف.
- `accounting-hub__head` والتبويبات واللوحات: نفس لغة اللون الفاتح.
- لوحات الاعتمادات/العناوين/المهام والبطاقات المشتركة: إطار وظل متوافقان.

## ما لم يتغيّر

- لا تغيير مسارات أو صلاحيات أو APIs أو منطق الجداول.
- لا إعادة كتابة لكل صفحة على حدة؛ التعديل عبر CSS مشترك في `portal-dashboard-modern.css` (PART 2 + PART 3).
- بوابة المستأجر تحصل على نفس اتجاه الكروم الفاتح للاتساق.
