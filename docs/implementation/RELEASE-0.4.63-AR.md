# BHD R 0.4.63 — زر التوقيع في صفحة التأكيد

## المطلوب
في صفحة `/stays/booking/confirmed` للحجوزات المدفوعة بلا توقيع (أو الحجوزات السابقة قبل تفعيل التوقيع): إظهار زر **توقيع عقد الإقامة** قبل أزرار PDF / متابعة الرحلة / بحث إقامة أخرى. النظام يتحقق تلقائياً من اكتمال التوقيع ويخفي الزر بعد الاعتماد.

## ما تغيّر
- إلغاء التحويل الإجباري من confirmed → sign.
- حقل حالة «العقد الإلكتروني»: بانتظار التوقيع / معتمد إلكترونياً من بن حمود.
- زر CTA يظهر فقط عندما: التوقيع مفعّل + الحجز مدفوع/مؤكد + `esignCompleted !== true`.

## اختبار
- [ ] `ST-0343C0F6` (مدفوع بلا توقيع): يظهر زر التوقيع أولاً.
- [ ] بعد التوقيع: الزر يختفي وتظهر حالة الاعتماد.
- [ ] مسار الدفع الجديد ما زال يفضّل التحويل إلى `/sign` بعد الدفع.
