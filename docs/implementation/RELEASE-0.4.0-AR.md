# الإصدار 0.4.0 — BHD R Stays (مراحل 0–8 خلف Feature Flag)

**التاريخ:** 2026-08-31  
**العلم:** `STAYS_PLATFORM_ENABLED` مغلق افتراضياً — لا يظهر للجمهور حتى التفعيل.

## ماذا أُضيف؟

مجال **الإقامات اليومية** مستقل عن البيع والإيجار الطويل:

- جداول `stay_*` + GiST لمنع تداخل الحجوزات + RLS.
- Domain: تسعير Decimal، آلة حالات الحجز، توافر `[)`.
- Nest `StaysModule` (فشل مغلق عند العلم off).
- لوحات المالك/المطور + `/stays` + تبويب الصفحة الرئيسية (عند التفعيل فقط).
- أساسات الحجز/العامل/بوابة الضيف والقنوات (stubs آمنة).

## ما لم يتغيّر؟

- `listingPurpose` ما زال `rent` / `sale` / `both` فقط.
- حجوزات الإيجار والعقود والفواتير الحالية كما هي.
- الموقع العام بلا تبويب إقامة يومية ما دام العلم مغلقاً.
