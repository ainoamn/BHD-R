## الملخص

1. **خطوة السعة والسياسات** أصبحت مقسّمة إلى أربعة أقسام مستقلة (عربي/إنجليزي + ترجمة لكل قسم):
   - السياسات العامة لمكان الإقامة
   - سياسات الإلغاء والتغيير
   - المناسبات والحفلات المسموح بها
   - خيارات الدفع
2. **التخزين:** `policies_json` jsonb يدعم الآن كائناً منظّماً `{ general, cancellation, events, payment }` مع توافق للبيانات القديمة (مصفوفة نصوص).
3. **العرض العام والمعاينة:** الصفحة العامة ومعاينة النشر تعرض الأقسام الأربعة بعناوين منفصلة.
4. **إصلاح صورة المعاينة:** في خطوة المراجعة والنشر، صور `/api/owner/media/` تُعرض عبر `<img>` مباشرة (بدون محسّن Next/Image) لأن الصور تحتاج جلسة المالك.
