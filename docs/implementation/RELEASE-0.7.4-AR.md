# الإصدار 0.7.4 — رسالة ترحيب تتبع مراحل حجز الضيف

**التاريخ:** 2026-10-11
**الصفحة:** `/[locale]/guest/stays/[id]?ref=…` (ومعها `&welcome=1` بعد الحجز مباشرة).

## المشكلة

- الرسالة أعلى صفحة الضيف كانت جملة قصيرة جافة لكل حالة («وصل طلب حجزك إلى المالك وهو قيد المراجعة…»)، بلا ترحيب باسمه ولا إرشاد لما سيحدث بعد ذلك.
- لم يكن هناك شكر ودعوة للعودة بعد المغادرة.

## الحل

### 1. رسالة لكل مرحلة (`lib/stay-guest-greeting.ts`)

`stayGuestGreeting` تعيد عنواناً ونصاً (وخطوات إرشاد أو زر حجز عند الحاجة) حسب حالة الحجز، بأسلوب ترحيبي مرح:

| المرحلة     | متى                                  | المضمون                                                                                        |
| ----------- | ------------------------------------ | ---------------------------------------------------------------------------------------------- |
| تقديم الطلب | `request_pending` مع `welcome=1`     | «يا هلا ويا مرحبا يا …!» وأربع خطوات مرقّمة: مراجعة المالك، الاعتماد والبريد، الوصول، المغادرة |
| قيد التدقيق | `request_pending`                    | «أهلاً بعودتك…»: الطلب بين يدي المالك أو ممثليه يفحصونه ويدققونه، والصفحة تتحدّث وحدها         |
| الدفع       | `payment_pending` / `payment_failed` | تذكير لطيف بإكمال الدفع، أو تشجيع على إعادة المحاولة                                           |
| الاعتماد    | `confirmed` / `pre_arrival`          | «أبشر، اعتُمد حجزك!» مع موعد الوصول، وتذكير بتوقيع العقد إن لزم                                |
| الوصول      | `checked_in`                         | «حيّاك الله، نوّرت المكان!» وتمنيات بإقامة ممتعة                                               |
| المغادرة    | `checked_out` / `closed`             | «شكراً من القلب!» ودعوة للعودة، وزر «احجز إقامتك القادمة»                                      |
| الانتهاء    | ملغى / مرفوض / منتهي / عدم حضور      | رسالة لطيفة وزر «تصفّح الإقامات»                                                               |

- الاسم يُعرض بلطف: الاسم المكتوب كله بحروف كبيرة (مثل `ABDUL HAMID AL RAWAHI`) يصبح `Abdul Hamid Al Rawahi`.
- النصوص بالعربية والإنجليزية.

### 2. العرض

- العنوان في أعلى الصورة مكان الرسالة القديمة.
- بطاقة جديدة في أول لوحة التفاصيل: العنوان، والنص، وخطوات مرقّمة، وزر الحجز.
- لون البطاقة يتبع المرحلة: أخضر للترحيب والاعتماد، وذهبي للمراجعة والدفع، وأزرق للإقامة، وبني ذهبي للوداع، ورمادي للانتهاء.
- مع المزامنة الحية (0.7.2) تتبدّل الرسالة وحدها عند تقدّم الحجز، دون تحديث الصفحة.
