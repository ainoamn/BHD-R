# الإصدار 0.3.9 — تبديل عرض القائمة / الشبكة / الجدول

**التاريخ:** 2026-08-31  
**الصفحة:** https://r.bhd-om.com/ar/properties  
**مشروع Vercel:** `bhd-r-api`

## ماذا تغيّر؟

في شريط نتائج العقارات يظهر مبدّل عرض:

- **قائمة** — صفوف Booking الأفقية (الافتراضي)
- **شبكة** — بطاقات شبكية
- **جدول** — جدول أعمدة (صورة، عقار، نوع، موقع، غرف، حمامات، مساحة، حالة، سعر)

يُحفظ الاختيار في `localStorage` (`bhd-r-props-view`).

## تحقق

1. افتح `/ar/properties`.
2. اضغط **جدول** أو **شبكة** أعلى النتائج بجانب «ترتيب».
3. أعد تحميل الصفحة — يبقى العرض المختار.
