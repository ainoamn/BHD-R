# BHD R 0.4.73 — تنقل بوابة المالك كصفحة واحدة

## المشكلة
التنقل في بوابة المالك كان يبدو كإعادة تحميل كاملة رغم التوثيق السابق (0.2.99 / WAZEN): تسخين البيانات يتأخر 2.5ث، وروابط الشريط لا تُprefetch إلا عند المرور، وأقسام التشغيل تُفك بعد 8 لوحات، وصفحات الإقامات/لوحة التحكم تُعاد من الصفر.

## ما تغيّر
1. تسخين فوري لأهم الأقسام ثم `warm-all` بدون انتظار 2.5ث.
2. `router.prefetch` متسلسل لكل روابط الشريط (بما فيها الإقامات عند التفعيل).
3. بعد التسخين: إبقاء كل لوحات التشغيل مركّبة (حتى ~24).
4. كاش صفحات غير-ops (لوحة التحكم، الإقامات، التفاصيل) للعودة الفورية.
5. TTL الكاش أطول (5 دقائق طازج / 30 دقيقة احتفاظ) وconcurrency التسخين = 4.
6. إخفاء شريط التقدم لأقسام التشغيل soft-nav حتى لا تبدو كتحميل مستند.

## تحقق
1. افتح `/ar/owner` وانتظر ~3–5ث دون نقر.
2. تنقّل: عقارات → فواتير → عقود → محاسبة — يظهر المحتوى فوراً من الذاكرة.
3. لوحة التحكم ↔ الإقامات ↔ التقويم — العودة لا تعيد بناء الصفحة من الصفر.
4. لا عاصفة شبكة متوازية ضخمة عند الفتح (prefetch متسلسل).
