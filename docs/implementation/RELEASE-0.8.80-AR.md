# الإصدار 0.8.80 — رجوع الطباعة المحاسبية إلى نفس التبويب

**التاريخ:** 2026-10-18

## المطلوب

من صفحة طباعة المستند المحاسبي، زر «العودة للمحاسبة» يعيد المستخدم إلى الصفحة/التبويب الذي كان يعمل فيه (مثل المستندات)، لا إلى لوحة المحاسبة الرئيسية.

## الحل

- عند فتح الطباعة يُمرَّر مسار المحاسبة الحالي (`from`).
- زر الرجوع يستخدم هذا المسار إن كان آمناً، وإلا يفتح التبويب المناسب لنوع المستند (`documents` / `journal` / `reports`) مع `open` عند الحاجة.

لا ترحيل قاعدة بيانات.
