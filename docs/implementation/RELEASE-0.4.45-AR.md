## الملخص

1. **صفحة تفاصيل الإقامة** تقبل `?unit=` و`?unitId=` (مع metadata) حتى لا يُهمَل ربط التقويم/الحجز.
2. **شارات القنوات:** شارة «إقامة» فقط عند `publish_status=published` و`enabled` (Web + Nest).
3. **معالج النشر:** بعد النشر يفتح `/stays/{slug}?unit=…` للوحدة المنشورة.
4. **Nest:** quote يقبل `unit`/`unitId` من الاستعلام؛ تسعير day-use / overnight-only مثل Neon.
