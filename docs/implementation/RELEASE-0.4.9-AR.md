# الإصدار 0.4.9 — قائمة حجوزات الإقامات للتشغيل (ops)

**التاريخ:** 2026-08-31  
**العلم:** مغلق افتراضياً — `/v1/stays/bookings` يردّ 404/401/403 حتى التفعيل والسماح للمؤسسة.

## ماذا أُضيف؟

- `GET /v1/stays/bookings?status=&propertyId=&limit=` — قائمة حقيقية من `stay_bookings` ضمن المؤسسة.
- `GET /v1/stays/bookings/:id` — تفاصيل تشغيلية (مرجع، تواريخ، مبالغ، مصدر).
- واجهة `/owner/stays/bookings` و`/developer/stays/bookings` بجدول بدل عدّاد فارغ.

## تحقق

| فحص | نتيجة |
| --- | --- |
| بلا جلسة → `/v1/stays/bookings` | 401 أو 404 |
| API/Web typecheck | قبل الدمج |

## تفعيل

نفس علم المنصة + allowlist؛ تظهر الحجوزات بعد مسار الضيف أو الإنشاء التشغيلي.
