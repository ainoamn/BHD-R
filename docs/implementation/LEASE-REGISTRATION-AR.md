# مرجع تسجيل عقد الإيجار

**آخر تحديث:** 2026-10-08 (الإصدار 0.6.1)
**الصفحة:** `/[locale]/owner/properties/[propertyId]?section=leasing`، زر «+ عقد تأجير يدوي» (وكذلك بوابة المطوّر)
**المصدر المنقول عنه:** نموذج عقد الإيجار في [bhd-om](https://github.com/ainoamn/bhd-om)

هذه الوثيقة مرجع دائم لطريقة تسجيل عقد الإيجار: الحقول، قواعد الحساب، شكل الطلب، ما يُحفظ في قاعدة البيانات، الأخطاء، والصلاحيات. تفاصيل الإصدار وما تغيّر فيه موجودة في [`RELEASE-0.6.1-AR.md`](./RELEASE-0.6.1-AR.md).

## 1. المسار من النموذج إلى قاعدة البيانات

1. **العرض:** يقرأ قسم التأجير `GET /api/portal/property-records/:propertyId/leasing`. يُرجع الوحدات (الإيجار، التأمين، الطابق، المساحة، العدادات)، ودفتر المستأجرين، وصلاحيات المستخدم (`viewer.canCreateLease`، `viewer.canSignContracts`).
2. **التعبئة:** `LeaseContractForm` يبني مسودة `LeaseTermsDraft`، ويحسب الملخص فوراً بالدالة `computeLeaseTerms`. لا يُرسل النموذج إذا فشل الحساب.
3. **الإرسال:** `POST /api/owner/properties/:propertyId/records` بالإجراء `create_lease`.
4. **الخادم:** `createManualLeaseContractOnNeon` يتحقق من الصلاحيات، ثم يعيد الحساب بنفس الدالة على عملة الوحدة، ثم ينشئ في معاملة واحدة: المستأجر، العقد، الإيجار، والشيكات.
5. **العرض بعد الحفظ:** صف العقد في التأجير والعقود يحمل `termsJson` و`tenantJson`، ويعرضهما `LeaseTermsView` في لوحة «التفاصيل المالية».

| الملف                                                                 | الدور                                              |
| --------------------------------------------------------------------- | -------------------------------------------------- |
| `apps/web/src/lib/lease-terms.ts`                                     | الثوابت، التواريخ، المبالغ، الجدول، الحساب والتحقق |
| `apps/web/src/components/lease-contract-form.tsx`                     | نموذج التسجيل                                      |
| `apps/web/src/components/lease-terms-view.tsx`                        | الملخص المالي ولوحة التفاصيل والتسميات             |
| `apps/web/src/app/api/owner/properties/[propertyId]/records/route.ts` | مخطط الطلب (zod) والإجراءات                        |

| `apps/web/src/lib/property-records-neon.ts`                           | القراءة لقسمي التأجير والعقود                      |

## 2. الحقول

### بيانات العقد الرئيسية

| الحقل                | المفتاح               | ملاحظات                                         |
| -------------------- | --------------------- | ----------------------------------------------- |
| الوحدة               | `unitId`              | من وحدات العقار. اختيارها يملأ الإيجار والتأمين |
| نوع العقد            | `contractType`        | `residential` سكني أو `commercial` تجاري        |
| نوع الاستعمال        | `usageType`           | يتبع نوع العقد افتراضياً، ويمكن تغييره          |
| رقم استمارة البلدية  | `municipalFormNo`     | اختياري، حتى 80 حرفاً                           |
| رقم العقد في البلدية | `municipalContractNo` | اختياري، حتى 80 حرفاً                           |

### المستأجر (`tenant`)

- **من دفتر العناوين:** `partyId` لطرف في نفس المؤسسة بدور مستأجر أو عميل محتمل. يُملأ الاسم والهاتف والبريد منه.
- **مستأجر جديد:** يُنشأ طرف جديد، أو يُستخدم الطرف الموجود بنفس البريد.

| الحقل                         | المفتاح                              | يظهر لـ |
| ----------------------------- | ------------------------------------ | ------- |
| النوع                         | `entityType`: `person` أو `company`  | الكل    |
| الاسم بالعربي (إلزامي)        | `nameAr`                             | الكل    |
| الاسم بالإنجليزي              | `nameEn`                             | الكل    |
| الرقم المدني، الجواز، الجنسية | `civilId`، `passport`، `nationality` | الفرد   |
| السجل التجاري وتاريخ انتهائه  | `crNumber`، `crExpiry`               | الشركة  |
| المفوّض بالتوقيع ورقمه المدني | `signatoryName`، `signatoryCivilId`  | الشركة  |
| الهاتف، البريد                | `phone`، `email`                     | الكل    |

### الإيجار والمدة

| الحقل            | المفتاح                               | ملاحظات                                                                         |
| ---------------- | ------------------------------------- | ------------------------------------------------------------------------------- |
| طريقة الحساب     | `rentCalcMode`: `full` أو `per_meter` | بالمتر: الإيجار الشهري = المساحة × سعر المتر                                    |
| الإيجار الشهري   | `monthlyRent`                         | أو `rentAreaSqm` و`rentPerSqm`                                                  |
| تاريخ التسليم    | `handoverOn`                          | اختياري، لا يكون بعد البداية                                                    |
| البداية والنهاية | `startsOn`، `endsOn`                  | النهاية بعد البداية. عدد الأشهر في النموذج يضبط النهاية = البداية + N شهر − يوم |
| يوم الدفع        | `paymentDay`                          | 1–31 (الافتراضي 5). يُقصّ لآخر الشهر، ويُحفظ في الإيجار حتى 28                  |
| طريقة الدفع      | `paymentMethod`                       | `cheque`، `cash`، `bank_transfer`                                               |
| دورية الدفع      | `paymentFrequency`                    | `monthly` 1، `bimonthly` 2، `quarterly` 3، `semiannual` 6، `annual` 12 شهراً    |
| خصم فترة السماح  | `graceAsDiscount`                     | يخصم قيمة أيام السماح من الإجمالي                                               |

### الضرائب والرسوم

| الحقل             | المفتاح                                | الافتراضي                                  |
| ----------------- | -------------------------------------- | ------------------------------------------ |
| القيمة المضافة    | `vatEnabled`، `vatRate`                | مفعّلة، 5%                                 |
| طريقة الضريبة     | `vatMode`: `with_rent` أو `separate`   | مع الإيجار                                 |
| عدد شيكات الضريبة | `vatChequeCount`، `vatChequeNumbers[]` | 1–24، في الوضع المنفصل فقط                 |
| رسوم البلدية 3%   | `municipalityFeeEnabled`               | مفعّلة                                     |
| رسوم التسجيل      | `registrationFee`                      | 1                                          |
| ضريبة أخرى        | `otherTaxName`، `otherTaxRate`         | لا تُحسب إلا بوجود الاسم ونسبة أكبر من صفر |

النسب تُقبل من 0 إلى 100 بخانتين عشريتين، وتُحفظ بنقاط الأساس (5% = 500).

### التأمين

- `deposit`: مبلغ التأمين.
- `depositItems[]` (حتى 20): `method` (`cash`، `cheque`، `bank_transfer`، `other`)، `amount`، `reference` (رقم الشيك أو المرجع)، `bankName`، `dueOn`.

### جدول الدفع والشيكات

- `chequeBankName` و`chequeAccountName`: بنك الشيكات وصاحب الحساب.
- `schedule[]` (1–240 سطراً): `dueOn`، `rent`، `chequeNumber`، `bankName`.
- يبني النموذج الجدول تلقائياً من التواريخ والإيجار والدورية ويوم الدفع، ويحتفظ بأرقام الشيكات المكتوبة عند إعادة البناء. التاريخ والمبلغ ورقم الشيك قابلة للتعديل في كل سطر.
- **الترقيم التلقائي:** من رقم الشيك الأول، بزيادة 1 لكل سطر مع الحفاظ على الأصفار والبادئة («000101» ← «000102»، «CHQ-9» ← «CHQ-10»).
- أرقام الشيكات وبنوكها لا تُحفظ إلا إذا كانت طريقة الدفع «شيك».

### المبالغ الإضافية والخصومات (`adjustments[]`، حتى 50)

| الحقل        | القيم                                                                                          |
| ------------ | ---------------------------------------------------------------------------------------------- |
| `kind`       | `add` إضافة، `discount` خصم                                                                    |
| `title`      | إلزامي، حتى 120 حرفاً (اقتراحات: إنترنت، مواقف سيارات، رسوم خدمات، كهرباء، ماء، صيانة…)        |
| `amount`     | أكبر من صفر                                                                                    |
| `recurrence` | `one_time` مرة واحدة، `with_renewal` مع كل تجديد، `every_3_months` كل 3 أشهر، `monthly` شهرياً |
| `scope`      | `contract_end` حتى نهاية العقد، `one_year` سنة، `custom_months` عدد أشهر (`months` 1–240)      |

### العدادات والملاحظات

- `electricityReading`، `waterReading`: قراءات التسليم. أرقام العدادات تُعرض من `utility_meters` للوحدة.
- `notes`: حتى 2000 حرف.

## 3. قواعد الحساب

كل المبالغ أعداد صحيحة بالوحدات الصغرى للعملة: 3 خانات للريال العماني والدينار البحريني والكويتي، وخانتان لغيرها. لا تُستخدم أعداد عشرية في المال.

### المدة

- **الأشهر الكاملة:** أكبر N بحيث (البداية + N شهر − يوم) لا تتجاوز النهاية. إضافة الأشهر تُقصّ لآخر الشهر (31 يناير + شهر = 28 أو 29 فبراير).
- **الأيام الزائدة:** من (البداية + N شهر) حتى النهاية، شاملة اليومين.
- **أيام السماح:** من التسليم إلى البداية.

### الجدول الافتراضي

- **سطر لكل دورة:** مبلغه = الإيجار الشهري × أشهر الدورة. آخر دورة قد تكون أقصر.
- **تاريخ الاستحقاق:** يوم الدفع في شهر بداية الدورة. في السطر الأول، إن وقع قبل البداية يصبح يوم البداية.
- **الأيام الزائدة:** سطر إضافي مبلغه الإيجار ÷ 30 × الأيام، مقرّباً.

### الإجماليات (`totals`)

| البند                                        | الحساب                                                                                                    |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `rentMinor`                                  | مجموع مبالغ الجدول كما أُدخلت                                                                             |
| `vatMinor`                                   | مع الإيجار: مجموع (النسبة × كل سطر). منفصلة: النسبة × إجمالي الإيجارات                                    |
| `municipalityFeeMinor`                       | 3% × إجمالي الإيجارات (قبل أي خصم)                                                                        |
| `registrationFeeMinor`                       | المبلغ المُدخل                                                                                            |
| `otherTaxMinor`                              | النسبة × إجمالي الإيجارات                                                                                 |
| `additionsMinor`                             | مجموع (المبلغ × عدد المرات) لبنود الإضافة                                                                 |
| `discountsMinor`                             | مجموع (المبلغ × عدد المرات) لبنود الخصم                                                                   |
| `graceDiscountMinor`                         | الإيجار ÷ 30 × أيام السماح، إذا فُعّل خصم السماح                                                          |
| `grandTotalMinor`                            | الإيجارات + الضريبة + البلدية + التسجيل + الضريبة الأخرى + الإضافات − (السماح + الخصومات)، ولا يقل عن صفر |
| `depositMinor`                               | التأمين، منفصل عن الإجمالي                                                                                |
| `monthlyVatMinor`، `monthlyRentInclVatMinor` | ضريبة الشهر والإيجار الشهري شاملاً الضريبة (للعرض)                                                        |

كل نسبة تُطبَّق بالتقريب لأقرب وحدة صغرى: المبلغ × نقاط الأساس ÷ 10000.

### عدد مرات البند الإضافي

أولاً تُحدَّد أشهر البند: مدة العقد، أو 12 بحد أقصى مدة العقد، أو العدد المخصص بحد أقصى مدة العقد.

| التكرار     | عدد المرات               |
| ----------- | ------------------------ |
| مرة واحدة   | 1                        |
| مع كل تجديد | 0 (لا يدخل في هذا العقد) |
| كل 3 أشهر   | ⌈أشهر البند ÷ 3⌉         |
| شهرياً      | أشهر البند               |

### شيكات الضريبة المنفصلة

- **المبالغ:** إجمالي الضريبة ÷ عدد الشيكات بالتقريب للأسفل. الشيك الأخير يأخذ الباقي، فيبقى المجموع مطابقاً.
- **تواريخ الاستحقاق:** موزّعة على مدة العقد. الشيك رقم i يستحق في يوم الدفع من الشهر ⌊i × الأشهر ÷ العدد⌋.

### مثال (من التشغيل على فرع الاختبار)

إيجار 800 ر.ع شهرياً لمدة 12 شهراً، ضريبة 5% بشيكين منفصلين، بلدية 3%، تسجيل 1، إضافة 15 شهرياً، خصم 50 مرة واحدة، و10 أيام سماح مخصومة:

| البند            | المبلغ (ر.ع)   |
| ---------------- | -------------- |
| الإيجارات        | 9,600.000      |
| القيمة المضافة   | 480.000        |
| رسوم البلدية     | 288.000        |
| رسوم التسجيل     | 1.000          |
| الإضافات         | 180.000        |
| خصم فترة السماح  | −266.667       |
| الخصومات         | −50.000        |
| **إجمالي العقد** | **10,232.333** |

## 4. الطلب

```http
POST /api/owner/properties/:propertyId/records
Content-Type: application/json
x-csrf-token: …
```

```json
{
  "action": "create_lease",
  "unitId": "uuid",
  "tenant": { "entityType": "person", "nameAr": "أحمد", "partyId": "uuid (اختياري)" },
  "terms": {
    "contractType": "residential",
    "usageType": "residential",
    "rentCalcMode": "full",
    "monthlyRent": "800",
    "startsOn": "2027-01-01",
    "endsOn": "2027-12-31",
    "paymentDay": "5",
    "paymentMethod": "cheque",
    "paymentFrequency": "monthly",
    "vatEnabled": true,
    "vatRate": "5",
    "vatMode": "with_rent",
    "vatChequeCount": "1",
    "municipalityFeeEnabled": true,
    "registrationFee": "1",
    "graceAsDiscount": true,
    "deposit": "800",
    "depositItems": [],
    "schedule": [{ "dueOn": "2027-01-05", "rent": "800", "chequeNumber": "000101" }],
    "vatChequeNumbers": [],
    "adjustments": []
  }
}
```

- **المبالغ:** كلها نصوص عشرية. الكائنات صارمة (`strict`)، فأي مفتاح غير معروف يرفض الطلب بـ `invalid_body`.
- **الحماية:** جلسة حيّة ورمز CSRF، وحد 30 طلباً في الدقيقة لكل مستخدم وعنوان.
- **الرد:** `{ contractId, contractReference, contractStatus, routedToManager, leaseId }`. `routedToManager: true` يعني أن العقد ينتظر اعتماد مالك المؤسسة.

## 5. ما يُحفظ

| الجدول                      | ما يُكتب                                                                                                                                                                                                            |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `parties` / `party_roles`   | المستأجر الجديد (`person` أو `company`) بدور `tenant`، أو إضافة الدور للطرف المختار                                                                                                                                 |
| `contracts`                 | رقم `CTR-YYYY-NNNNNN`، النوع `lease`، والقيمة = `grandTotalMinor`                                                                                                                                                   |
| `contracts.payloadSnapshot` | `leaseTerms` (كائن `LeaseTerms` الإصدار 1 كاملاً)، `tenantDetails`، `notes`، والمصدر `manual`                                                                                                                       |
| `contract_signatures`       | توقيع المالك باسم المستخدم إذا كان يملك `contract.sign`                                                                                                                                                             |
| `leases`                    | `rentMinor` = الإيجار الشهري، `depositMinor`، `billingDay` = يوم الدفع (حتى 28)، والتواريخ                                                                                                                          |
| `approval_requests`         | طلب اعتماد مُسنَد لمالك المؤسسة إذا لم يملك المستخدم صلاحية التوقيع                                                                                                                                                 |
| `cheques`                   | سطر لكل شيك له رقم: الإيجار (المبلغ شاملاً الضريبة إن كانت مع الإيجار)، الضريبة المنفصلة، والتأمين. البنك من السطر أو بنك الشيكات، ويستحق شيك التأمين بلا تاريخ في يوم البداية. الحالة `pending`، والطرف = المستأجر |

**كائن `leaseTerms`** (الإصدار `version: 1`) يحفظ المدخلات بعد التنظيف ونتائج الحساب:

- `currency`، `digits`
- `monthlyRentMinor`، `rentCalcMode`، `rentAreaSqm`، `rentPerSqmMinor`
- `startsOn`، `endsOn`، `months`، `extraDays`، `handoverOn`، `graceDays`، `graceAmountMinor`، `graceAsDiscount`
- `paymentDay`، `paymentMethod`، `paymentFrequency`
- `vat` { `enabled`، `rateBasisPoints`، `mode`، `chequeCount` }، `municipalityFee`، `otherTax`
- `schedule[]` { `index`، `periodFrom`، `periodTo`، `dueOn`، `rentMinor`، `vatMinor`، `totalMinor`، `chequeNumber`، `bankName`، `extraDays` }
- `vatCheques[]`، `adjustments[]` (مع `occurrences` و`lineTotalMinor`)، `depositItems[]`
- `meters`، `notes`، `totals`

أي تغيير مستقبلي في شكل الكائن يجب أن يرفع `LEASE_TERMS_VERSION`، وأن يبقى `parseLeaseTerms` في `lease-terms-view.tsx` قادراً على قراءة الإصدار 1.

## 6. الأخطاء

| الرمز                     | الحالة | السبب                                                                    |
| ------------------------- | ------ | ------------------------------------------------------------------------ |
| `invalid_body`            | 400    | الطلب لا يطابق المخطط                                                    |
| `invalid_dates`           | 400    | تاريخ غير صالح، النهاية ليست بعد البداية، أو التسليم بعد البداية         |
| `invalid_amount`          | 400    | الإيجار صفر أو غير صالح، أو المساحة وسعر المتر غير صالحين                |
| `invalid_schedule`        | 400    | جدول فارغ أو أطول من 240، تاريخ أو مبلغ غير صالح، أو مجموع الإيجارات صفر |
| `invalid_terms`           | 400    | يوم دفع أو نسبة أو رسوم أو تأمين غير صالح، أو بند إضافي أو تأمين ناقص    |
| `duplicate_cheque_number` | 400    | رقم شيك مكرّر بين شيكات الإيجار والضريبة والتأمين في نفس العقد           |
| `forbidden`               | 403    | لا يملك المستخدم `contract.create` و`lease.create`                       |
| `party_not_found`         | 404    | المستأجر المختار ليس في هذه المؤسسة                                      |
| `cheque_number_taken`     | 409    | رقم شيك مستخدم سابقاً في المؤسسة                                         |
| `lease_overlap`           | 409    | إيجار آخر متداخل على نفس الوحدة                                          |

النموذج يعرض لكل رمز رسالة عربية من `ERROR_TEXT` في `property-section-records.tsx`.

## 7. الصلاحيات والخصوصية

| الإجراء                  | الصلاحية                                        |
| ------------------------ | ----------------------------------------------- |
| فتح النموذج وإنشاء العقد | `contract.create` + `lease.create`              |
| اعتماد العقد فوراً       | `contract.sign` (مالك المؤسسة)                  |
| رؤية دفتر المستأجرين     | `lease.create`، وليس حساب مالك محصوراً بعقاراته |

- يُقفل إنشاء العقود على نفس الوحدة بقفل استشاري داخل المعاملة، فلا يمر عقدان متداخلان في نفس اللحظة.
- القراءة والكتابة داخل `withinViewerTenant`، فلا تصل لبيانات مؤسسة أخرى.

## 9. حدود معروفة

- لا يُنشأ جدول فوترة ولا فواتير من جدول الدفع. الشيكات تُسجَّل للمراجعة المحاسبية فقط.
- الرقم المدني والجواز والسجل التجاري في نسخة العقد، وليست في حقول الطرف المشفّرة الخاصة بخادم Nest.
- رسوم البلدية على الإيجارات قبل الخصومات، وخصم السماح اختياري. هكذا يعمل bhd-om.
- صفحة تفاصيل العقد (`/owner/contracts/:id`) لا تعرض الشروط بعد. تُعرض في لوحة «التفاصيل المالية» داخل صفحة العقار.
- لا يوجد تعديل للعقد بعد إنشائه من هذا النموذج.
