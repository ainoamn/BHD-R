# الإصدار 0.4.20 — إصلاح تفعيل إعداد الإقامات (Allowlist)

**التاريخ:** 2026-09-01

## المشكلة

معالج «إعداد الإقامة اليومية» أظهر:
«الخدمة غير مفعّلة — تواصل مع الإدارة لتفعيل STAYS_PLATFORM_ENABLED»

بينما القائمة الجانبية للإقامات كانت ظاهرة (أي العلم على Vercel مفعّل).

**السبب الحقيقي:** `STAYS_ORG_ALLOWLIST` فارغ على Nest (Render) → كل طلبات `/v1/stays/*` التشغيلية تردّ **403** → فحص الصحة يفشل → المعالج يُعطَّل برسالة خاطئة.

## الإصلاح

- Allowlist فارغ + `STAYS_PLATFORM_ENABLED=true` → تُسمح كل المؤسسات (pilot مفتوح).
- قائمة UUID صريحة ما زالت تقيّد المؤسسات.
- رسالة المعالج تعرض سبب Nest الفعلي (403/401/404).

## مطلوب منك (Render)

1. تأكد: `STAYS_PLATFORM_ENABLED=true`
2. اختياري: `STAYS_ORG_ALLOWLIST=*` أو اتركه فارغاً بعد نشر 0.4.20
3. **Manual Deploy** لخدمة Nest (و Worker إن وُجد) من `main`

بدون إعادة نشر Nest لن يُطبَّق الإصلاح على API.
