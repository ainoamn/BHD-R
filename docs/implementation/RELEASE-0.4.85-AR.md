# إصدار 0.4.85 — شاشة حجوزات ومعاينات موحّدة

**تاريخ:** 2026-09-11

## لماذا كان هناك نافذتان؟

| مسار | سابقاً |
| --- | --- |
| `/owner/bookings` | حجوزات الإيجار + المعاينات + الحجوزات المؤقتة |
| `/owner/stays/bookings` | حجوزات الإقامة اليومية فقط |

## بعد الدمج

- شاشة واحدة: **الحجوزات والمعاينات** → [`/ar/owner/bookings`](https://r.bhd-om.com/ar/owner/bookings)
- تبويبات: **الكل · يومي · شهري · سنوي · بيع**
- `/owner/stays/bookings` يُحوَّل تلقائياً إلى `/owner/bookings?tab=daily`
- تفاصيل عقد الإقامة تبقى على `/owner/stays/bookings/[id]`
- مجموعة «الإقامات اليومية» في الشريط تبقى للتقويم والأسعار فقط
