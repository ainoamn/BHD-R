# الإصدار 0.8.74 — مساحة عمل محاسبية: مستندات، تفاصيل قيد، وواجهة احترافية

**التاريخ:** 2026-10-18  
**الحالة:** جاهز للرفع

## المشكلة

المستخدم على [`/ar/owner/accounting`](https://r.bhd-om.com/ar/owner/accounting) رأى واجهة بدائية بلا إيصالات/فواتير، بلا فتح للمعاملة، وبلا تتبّع أو ملاحظات، مع صعوبة إدخال قيود يومية — بعيداً عن مواصفات المنصة المحاسبية العالمية في وثيقة المتطلبات.

## الحل

1. **تبويب المستندات:** فواتير مطالبة، إيصالات قبض (إيجار/إقامة)، وقيود مصدر مرتبطة.
2. **درج تفاصيل القيد:** أسطر الحسابات، الأبعاد (طرف/عقار/وحدة)، المذكرات، سجل التتبع (إنشاء/ترحيل/عكس)، وترحيل أو عكس من التفاصيل.
3. **دفتر يومية عملي:** نموذج قيد بارز، تهيئة دليل تلقائية إن كان فارغاً، صفوف قابلة للنقر لفتح المعاملة.
4. **واجهة مساحة عمل:** رأس واضح، تبويبات أساسية، جداول تفاعلية، ألوان خضراء هادئة متوافقة مع بوابة المالك — دون مظهر «بطاقات صفرية» فقط.
