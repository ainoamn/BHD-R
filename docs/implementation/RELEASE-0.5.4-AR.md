# الإصدار 0.5.4 — الدفع الفوري لحجوزات الإقامة اليومية وتصحيح رسائل الدفع

**التاريخ:** 2026-10-08
**الصفحة:** `/[locale]/stays/[slug]/book`

## المشكلة

بعد تأكيد الحجز، كانت الصفحة تعرض: «بوابة الدفع غير مفعّلة في هذه البيئة. يمكنك المحاولة من زر ادفع الآن»، مع أن بوابة الدفع مفعّلة فعلاً.

## السبب

1. **الوحدة كانت على وضع «طلب حجز»** (خيار «حجز فوري» غير مفعّل في إعدادات الإقامة؛ القيمة الافتراضية في قاعدة البيانات `false`).
   - الحجز يُنشأ عندها بحالة «بانتظار الاعتماد» (`request_pending`) بدل «بانتظار الدفع» (`payment_pending`).
2. **الدفع مرفوض لهذه الحالة:** خدمة جلسة الدفع لا تقبل إلا حجزاً «بانتظار الدفع»، فترد بخطأ 409 ورمز `booking_not_payable`.
3. **رسالة خاطئة:** الصفحة كانت تفسّر أي خطأ 409 من الدفع على أنه «بوابة الدفع غير مفعّلة».
4. **طريق مسدود:** لا يوجد في النظام حالياً زر للمالك لاعتماد الطلب، فلا يستطيع الضيف الدفع أبداً، وتبقى التواريخ محجوزة حتى يُلغى الطلب.

## ما تغيّر

### الخادم

- حجز الإقامة من الموقع يُنشأ دائماً **فورياً** بحالة «بانتظار الدفع»، فيُحوَّل الضيف مباشرة إلى بوابة الدفع.
- يتأكّد الحجز بعد نجاح الدفع كما في السابق.
- الملف: `apps/web/src/lib/public-stays-booking-neon.ts`.

### صفحة الحجز

دالة جديدة `paymentErrorMessage` تعرض رسالة دقيقة حسب رمز الخطأ، في التحويل التلقائي بعد الحجز وفي زر «ادفع الآن»:

| رمز الخطأ | الرسالة |
| --- | --- |
| `payment_gateway_inactive` | بوابة الدفع غير مفعّلة حالياً. |
| `booking_not_payable` | هذا الحجز لم يعد قابلاً للدفع (قد يكون أُلغي أو انتهت مهلته). ابدأ حجزاً جديداً. |
| `already_paid` | تم دفع هذا الحجز مسبقاً. |
| `intent_not_payable` | انتهت صلاحية عملية الدفع لهذا الحجز. ابدأ حجزاً جديداً. |
| غير ذلك | رسالة الخادم أو رسالة الاتصال المعتادة. |

### إعدادات المالك

خانة «حجز فوري (دون انتظار موافقتي)» لم يعد لها أثر، فاستُبدلت بملاحظة: «الحجز من الموقع فوري: يدفع الضيف مباشرة ويتأكّد الحجز بعد الدفع.» في مكانين:

- صفحة تعديل العقار (`property-stay-settings-panel.tsx`)؛
- معالج إعداد الإقامة (`stay-setup-wizard.tsx`).

القيمة المخزّنة `instant_book` باقية في قاعدة البيانات دون ترحيل، لاستخدامها إن بُني نظام موافقة المالك لاحقاً.

## ملاحظات

- **الطلبات القديمة** التي أُنشئت بحالة «بانتظار الاعتماد» قبل هذا الإصدار تبقى كما هي. يمكن للمالك رفضها من شاشة الحجوزات لتحرير تواريخها، ثم يحجز الضيف من جديد.
- **نظام موافقة المالك** (الضيف يرسل الطلب، والمالك يعتمده، ثم يصل الضيف رابط الدفع) غير موجود بعد، ويمكن بناؤه لاحقاً عند الحاجة.
