# الإصدار 0.7.1 — تسجيل دخول ومغادرة ضيف الإقامة، وصفحة واحدة لتفاصيل الحجز

**التاريخ:** 2026-10-11
**الصفحات:** تبويب الحجوزات في صفحة العقار `/[locale]/owner/properties/[id]?section=bookings`، وصفحة الضيف `/[locale]/guest/stays/[id]`، ورابط `/[locale]/stays/booking/confirmed`.

## المشكلة

- بعد اعتماد حجز الإقامة (مثل ST-6C2A8BBC) يبقى «مؤكّد» ولا يتقدّم. لا يوجد زر لتسجيل وصول الضيف، ولا مكان لوقت الاستلام أو الملاحظات.
- زر المغادرة موجود فقط في صفحة حجوزات الإقامات، ويمر عبر خادم Nest بلا وقت ولا ملاحظات.
- الضيف لا يرى متى سُجّل دخوله أو مغادرته.
- للحجز صفحتان بتصميمين مختلفين: صفحة التأكيد بعد الحجز (`/stays/booking/confirmed`) وصفحة تفاصيل الإقامة (`/guest/stays/[id]`).

## الحل

### 1. مراحل الحجز في تبويب الحجوزات

- الحجز المؤكّد يظهر **«بانتظار الدخول»** (شارة زرقاء).
- زر **«تسجيل الدخول»** يفتح نموذجاً تحت الصف: تاريخ ووقت الاستلام والدخول (افتراضياً الآن بتوقيت مسقط) وملاحظات.
- بعد التأكيد يصبح الحجز **«بانتظار المغادرة»**، ويظهر زر **«تسجيل المغادرة»** بالنموذج نفسه.
- بعد المغادرة: «تم المغادرة».
- عمود جديد «الدخول والمغادرة» يعرض الوقتين والملاحظات.
- أزرار التصفية تستخدم المراحل نفسها.

### 2. الحفظ (`lib/stay-arrival-neon.ts`)

- `recordStayStampOnNeon`:
  - يفحص صلاحية `stay.booking.manage`، وشرط المنظمة، وملكية العقار للمالك.
  - يفحص الانتقال عبر آلة الحالات: من مؤكّد أو قبل الوصول إلى «تم الدخول»، ومن «تم الدخول» إلى «تم المغادرة».
  - يرفض وقتاً في المستقبل (بسماحية 15 دقيقة)، أو مغادرة قبل وقت الدخول المسجّل.
  - يسجّل الوقت والملاحظات واسم من سجّلها في `metadata_json` لسجل حالات الحجز، فلا حاجة لتعديل قاعدة البيانات.
  - يكتب حدث سير العمل، وعند المغادرة حدث `stay.checked_out` كما في Nest، فينشئ العامل مهمة التنظيف.
- آلة الحالات: صار مسموحاً الانتقال من «مؤكّد» إلى «تم الدخول» مباشرة.
- المسار: `POST /api/owner/properties/[id]/records` بالإجراءين `check_in` و`check_out`.

### 3. صفحة الضيف

- مراحل الحجز (الوصول، المغادرة) تعرض الوقت الفعلي تحت كل مرحلة.
- «تفاصيل الحجز» تعرض وقت الدخول والاستلام، وملاحظات الدخول، ووقت المغادرة، وملاحظات المغادرة.

### 4. صفحة واحدة للحجز

- `/stays/booking/confirmed` صار تحويلاً إلى `/guest/stays/[id]?ref=…&welcome=1`.
- الرابط نفسه باقٍ لأن بوابة الدفع وصفحة التوقيع ورسائل البريد تستخدمه.
- صفحة الضيف أخذت ما كان في صفحة التأكيد: رسالة ترحيب بعد الحجز، وزر «توقيع عقد الإقامة» عند الحاجة، وحالة العقد، وتنبيه إرسال البريد، وحفظ الرحلة لجرس التنبيهات.
