# الإصدار 0.3.6 — وحدات شاغرة في «حجز جديد»

**التاريخ:** 2026-08-31

## المشكلة

عند إنشاء حجز جديد من «الحجوزات والمعاينات» قائمة الوحدات فارغة لأن الخيارات كانت تعتمد على Nest فقط.

## الإصلاح

1. تحميل سياق النماذج (وحدات/عقارات/أطراف) من **Neon**.
2. الوحدة الشاغرة = بلا عقد ساري + بلا حجز/حجز مؤقت فعّال.
3. قائمة «حجز جديد» تعرض الشاغرة فقط مع رسالة إن لم يوجد شيء.

## تحقق

بوابة المالك → الحجوزات والمعاينات → ＋ حجز جديد — تظهر الوحدات الشاغرة فقط.
