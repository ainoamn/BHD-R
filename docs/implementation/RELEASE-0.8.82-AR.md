# الإصدار 0.8.82 — طباعة مرة واحدة + تمييز المعاملة عند الرجوع

**التاريخ:** 2026-10-18

## المطلوب

1. زر الطباعة لا يفتح الصفحة الحالية وصفحة إضافية معاً.
2. عند الرجوع من صفحة الطباعة يُظلَّل/يُعلَّم المستند أو القيد الذي طُبع.

## الحل

- إزالة الاعتماد على قيمة إرجاع `window.open(..., 'noopener')` (كانت `null` رغم نجاح الفتح فيفتح التبويب الحالي أيضاً).
- مسار الرجوع يحمل `focus` (و`open` للقيود)؛ صف المستند/القيد يُبرز ويُمرَّر إليه في العرض.

لا ترحيل قاعدة بيانات.
