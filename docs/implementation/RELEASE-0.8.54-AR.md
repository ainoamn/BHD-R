# الإصدار 0.8.54 — الفريق كاملاً: أدوار متعددة، وأدوار مخصصة، وملاك العقارات، والمستأجرون

**التاريخ:** 2026-10-13

## المشكلة

صفحة الفريق (`/owner/team`) كانت تعطي كل عضو دوراً واحداً من خمسة أدوار: مدير، ومدير عقارات، ومحاسب، وفني صيانة، ومدقق. فلم يكن ممكناً:

- إضافة موظف إداري، أو مستشار قانوني، أو حارس مبنى؛
- منح العضو أكثر من دور؛
- منحه بعض صلاحيات المحاسب دون الدور كاملاً؛
- حفظ دور خاص بالمنشأة؛
- منح مالك عقار دخولاً يرى فيه عقاراته فقط؛
- رؤية المستأجرين الذين لهم دخول، أو إيقاف دخولهم.

وكشفت مراجعة الأمان أن بوابة المالك تفتح كل الأقسام لكل دور. مثلاً كان فني الصيانة يفتح جهات الاتصال والفواتير، وبعض مسارات الكتابة لم تكن تفحص الصلاحية.

## الحل

### الأدوار

- **أدوار جديدة:**
  - **موظف إداري:** الاستقبال، والطلبات، والمعاينات، والحجوزات، وجهات الاتصال. لا يرى المالية ولا العقود.
  - **مستشار قانوني:** العقود ونماذجها، والقضايا القانونية، ومراجعة الشيكات.
  - **حارس مبنى:** يرى العقارات والحجوزات القادمة، ويفتح طلبات الصيانة والمهام اليومية.
  - **مالك عقار:** يرى عقاراته فقط.
- **«المدير» صار «مدير عام»**، ولم تتغير صلاحياته.
- **أكثر من دور للعضو الواحد:** مثلاً فني صيانة وحارس مبنى معاً. وصلاحياته مجموع صلاحيات أدواره.
- **صلاحيات منفصلة فوق الأدوار:** 33 صلاحية في سبع مجموعات، منها عشر صلاحيات مالية منفصلة: عرض الفواتير، وإصدارها، وإلغاؤها، وعرض المدفوعات، وتسجيلها، وتحويل التأمين، والمطابقة، والشيكات، وعرض الحسابات، والقيود.
  - ما يأتي مع الدور يظهر مؤشَّراً عليه ومقفلاً، بعبارة «ضمن الدور».
  - لكل مجموعة زر «تحديد الكل».
- **الأدوار المخصصة:** ينشئها المالك باسم عربي وإنجليزي ووصف وصلاحيات يختارها، مثل «محاسب استلام». تُحفظ للمنشأة وتُمنح لأي عضو.
  - تعديل الدور يسري على كل من يحمله فوراً، وحذفه يسحبه منهم.
  - لا يمنح أحدٌ دوراً مخصصاً إلا إن كان يملك كل صلاحياته. و«إدارة الفريق» للمالك وحده.

### صفحة الفريق

خمسة تبويبات:

- **الفريق:** الأعضاء وأدوار كل منهم وصلاحياته الإضافية. زر «إضافة عضو» يفتح نموذجاً بعرض الصفحة لاختيار الأدوار والصلاحيات.
- **ملاك العقارات:** منح مالك مسجَّل دخولاً ببريده. يُختار المالك من قائمة ملاك العقارات مع عدد عقارات كل منهم. ويمكن تغيير المالك المرتبط بالحساب، أو تعطيل الدخول، أو إزالته. لا يُحتسب ضمن مقاعد الفريق.
- **المستأجرون:** من لهم دخول إلى بوابة المستأجر، مع البحث وتعطيل الدخول أو تفعيله.
- **الأدوار المخصصة:** إنشاء الأدوار وتعديلها وحذفها، مع عدد حاملي كل دور.
- **دليل الأدوار:** وصف كل دور مجمَّعاً: الإدارة، والمالية والتدقيق، والشؤون الإدارية والقانونية، والميدان، ثم المالك وملاك العقارات والمستأجرون.

### ما يفتحه كل دور

- **الشريط الجانبي ولوحة التحكم:** يعرضان فقط الأقسام والأزرار التي يفتحها دور المستخدم.
- **أقسام بوابة المالك:** يفتح كل قسم بالصلاحية المطلوبة له، والقسم غير المسموح يرجع 403. وتُحذف من البيانات المرافقة القوائم التي لا يملك المستخدم صلاحيتها، مثل جهات الاتصال والفواتير والحسابات.
- **مالك العقار:**
  - يرى عقاراته وحجوزاتها فقط.
  - صفحة عقار غيره، أو صفحات الأسعار وإعداد الإقامة والشروط وإضافة العقار، تعرض «الصفحة غير متاحة».
  - في صفحة عقاره يرى أقسامه (الحجوزات، والعقود، والتأجير، والصيانة، والفواتير) دون تعديل أو أرشفة.
- **مسارات الكتابة:** أُضيف فحص الصلاحية إلى:
  - أرشفة العقار واستعادته وحذفه النهائي: الحذف يتطلب صلاحية الأرشفة.
  - أسعار الأيام وتقويم الإقامة وإعدادها.
  - سجلات العقار.
  - تفاصيل حجز الإقامة.

## التحقق

- `tsc` للويب بلا أخطاء. و`tsc` لـNest بلا أخطاء جديدة، عدا الخطأ السابق في `@bhd-r/observability` غير المبنية محلياً.
- `eslint`: لا أخطاء في الأسطر المعدّلة.
- اختبارات الوحدة: 13 اختباراً للفريق والأدوار والوصول تنجح. وما يفشل كان يفشل قبل هذا الإصدار: CSRF لمسارات الضيوف العامة، وثلاثة مسارات للمالك تعيد رموز أخطاء محددة دون `clientSafeErrorCode`.
- **على فرع Neon مؤقت منسوخ من الإنتاج:** طُبّق الترحيل 0030، ثم:
  - أُنشئ دور «محاسب استلام».
  - أُضيف عضو بدورَي حارس مبنى ومحاسب استلام مع «عرض جهات الاتصال». ثم عُدّلت أدواره إلى فني صيانة وحارس مبنى ومحاسب استلام مع «التقارير»، فتغيّر رقم جلسته فوراً.
  - رُفض كلٌّ من: عضو بلا دور، ودور «المالك»، ومالك عقار غير مسجّل، وCSRF خاطئ.
  - أُضيف مالك عقار مرتبط بمبنى واحد. فرأى «مبنى النور» فقط. وأقسام جهات الاتصال والفواتير والمدفوعات والحسابات والتأجير والصيانة والفريق ترجع 403. وأرشفة عقاره ترجع 403. وصفحة عقار غيره وصفحة الأسعار تعرضان «الصفحة غير متاحة». ولوحة التحكم تعرض روابط العقارات والحجوزات فقط.
  - مستأجر تجريبي: عُطّل دخوله ثم أُعيد. ورفض مسار المستأجرين تعديل موظف.
  - لوحة تحكم المالك نفسه بقيت بكل روابطها.
- حُذف الفرع المؤقت والملفات المؤقتة.
