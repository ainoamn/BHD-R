# الإصدار 0.4.53 — حجز بدون مبيت + تصميم ملء الشاشة + توقيع إلكتروني + قفل التزامن

**التاريخ:** 2026-09-03  
**الإنتاج:** https://r.bhd-om.com  
**Commit:** `5f95581`

## ما تغيّر

1. **إقامة بدون مبيت / مبيت فقط:** نفس اليوم مسموح؛ المغادرة الحصرية داخلياً = اليوم+1.
2. **فترات نصف اليوم:** `lock_slot` = morning / evening / full (هجرة `0023_stay_lock_slots.sql`).
3. **الهاتف إلزامي** في خطوة بيانات الضيف.
4. **نافذة موافقة قبل الدفع** ثم بوابة الدفع.
5. **إعادة تصميم صفحة الحجز** بملء الشاشة + شعار BHD على صورة الغلاف وبطاقة الدفع.
6. **بعد الدفع:** مسار توقيع إلكتروني `/stays/booking/sign` (توقيع + بطاقة أمام/خلف + سيلفي) — يُعطَّل بـ `STAY_ESIGN_REQUIRED=0`.
7. **سباق الحجز:** عند الدفع يُعاد فحص الفترة؛ إن نُفدت تظهر رسالة اختيار يوم آخر.
8. **عقد المالك** يعرض التوقيع وصور الهوية عند اكتمالها.

## هجرة قاعدة البيانات (مطلوبة)

نفّذ على Neon:

`packages/db/migrations/custom/0023_stay_lock_slots.sql`

بدونها قد تفشل أقفال نصف اليوم (عمود `lock_slot` / الـ trigger).
