# الإصدار 0.3.0 — تنقل عميل فوري مع التحميل الخلفي

**التاريخ:** 2026-08-31

## لماذا بقي بعض التنقل ~10 ثوانٍ بعد 0.2.99؟

التحميل الخلفي يملأ الذاكرة، لكن صفحات الأقسام كانت ما زالت Server Components فتنتظر رحلة RSC عند كل نقرة.

## الإصلاح

1. صفحات `owner/*` و`developer/*` التشغيلية أصبحت Client Components ترسم من الكاش فوراً.
2. إن كانت البيانات دافئة: لا طلب API إضافي عند التنقل.
3. هيكل تحميل خفيف بدل شاشة فارغة أثناء أول زيارة لقسم لم يُحمَّل بعد.
4. تدفئة عند مرور المؤشر على رابط القائمة.

يعمل مع **0.2.99** (warm-all عند فتح البوابة).
