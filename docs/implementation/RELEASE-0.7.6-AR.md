# الإصدار 0.7.6 — العقد كاملاً كأصل المستند، مع الطباعة والتصدير والمشاركة والإرسال

**التاريخ:** 2026-10-11
**الصفحة:** `/[locale]/owner/contracts/[contractId]` (وكذلك `developer` و`tenant`)

## المشكلة

- صفحة العقد كانت تعرض ملخصاً: رقم العقد والأطراف وحالة الاعتماد وبصمات التواقيع مختصرة.
- لا تظهر الشروط التي قبلها الضيف، ولا صورة توقيعه، ولا وثائق الهوية، ولا أوقات الاستلام والتسليم، ولا الملاحق، ولا سجل العقد.
- لا يمكن طباعة العقد أو حفظه PDF أو مشاركته أو إرساله للطرف الآخر.

## الحل

### 1. العقد كوثيقة ورقية

صفحة العقد صارت ورقة واحدة بترويسة الشركة (الشعار والاسم) وتذييلها (العنوان ووسائل التواصل)، وختم حالة العقد. أقسامها مرقّمة:

| القسم             | المحتوى                                                                                                                |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| أطراف العقد       | المالك ومن اعتمد العقد نيابة عنه، والضيف أو المستأجر أو المشتري مع بريده وهاتفه                                        |
| محل العقد         | العقار والوحدة ونوع الإقامة                                                                                            |
| المدة والقيمة     | البدء والانتهاء، عدد الليالي والضيوف، قيمة الإقامة والتأمين، ومرجع الحجز (رابط إلى صفحة الضيف)                         |
| الاستلام والتسليم | وقت الوصول ووقت المغادرة مع ملاحظاتهما (لعقود الإقامة)                                                                 |
| نص العقد          | نص قالب العقد المحفوظ                                                                                                  |
| الشروط والأحكام   | الشروط المرقّمة بالعربية والإنجليزية كما قبلها الضيف، مع تاريخ القبول                                                  |
| التواقيع          | لكل طرف: صورة التوقيع الإلكتروني أو ختم «موقّع إلكترونياً»، الاسم والبريد، طريقة التوقيع، الوقت، والبصمة الرقمية كاملة |
| المرفقات والوثائق | صور الهوية (الوجهان) والصورة الشخصية للتحقق، ونسخة PDF المختومة إن وُجدت                                               |
| الملاحق           | ملاحق التجديد المرتبطة، أو رابط العقد الأصلي إن كان هذا ملحقاً                                                         |
| سجل العقد         | الإنشاء، الاعتماد، قبول الشروط، كل توقيع، الوصول، المغادرة، الاكتمال — مرتبة زمنياً                                    |

### 2. شريط الأدوات

- **طباعة:** تطبع الوثيقة وحدها دون قوائم البوابة.
- **تصدير PDF:** يفتح نافذة الطباعة مع تلميح «اختر حفظ بصيغة PDF»، فتحفظ نسخة مطابقة. اسم الملف المقترح رقم العقد ونوعه.
- **النسخة المختومة:** تظهر إن وُلّد للعقد ملف PDF في المخزن.
- **مشاركة:** قائمة المشاركة في الجوال، أو نسخ الرابط في الحاسوب.
- **إرسال بالبريد / واتساب:** رسالة جاهزة إلى الضيف أو المستأجر (بريده أو رقمه من العقد) فيها ملخص العقد ورابط صفحته: صفحة الحجز للضيف، أو العقد في بوابة المستأجر.

### 3. حماية الوثائق

- الصور تُخدَم من مسار محمي جديد `GET /api/portal/contracts/[contractId]/files/[file]`، بنفس فحوص الصفحة: الجلسة، صلاحية `contract.read`، المؤسسة، ونطاق الطرف.
- صور الهوية والصورة الشخصية لا تظهر إلا لمن يملك `stay.booking.manage` أو للمستأجر نفسه. غيرهم يرى التوقيع فقط مع تنبيه بأن الوثائق محجوبة.
- الصفحة لا تحمّل الصور مع البيانات، بل تعرف فقط أيّها موجود. الصورة تُطلب عند عرضها وتُخزَّن مؤقتاً في المتصفح 5 دقائق (`private`).
- نص القالب يمرّ بمنقٍّ يسمح بوسوم النص فقط (عناوين، فقرات، قوائم، تشديد) ويحذف كل السمات والسكربتات.

### 4. التنفيذ

- `lib/contract-detail-neon.ts`: فحص الوصول صار مشتركاً بين الصفحة ومسار الملفات. أُضيف `document` إلى `ContractDetail`: القالب، الترويسة، الملاحق والعقد الأصلي، أدلة التواقيع، الشروط عبر `bookingTermsDocument`، بيانات الإقامة من `lookupPublicStayBookingOnNeon` مع التحقق من المؤسسة، وقائمة الملفات. وأُضيف `readContractFile`.
- `lib/contract-document.ts` (جديد): الأنواع و`sanitizeContractHtml`.
- `components/contract-detail-view.tsx`: الوثيقة الكاملة. إن لم تتوفر قراءة Neon يبقى العرض المختصر من Nest كما كان.
- `components/contract-document-toolbar.tsx` (جديد): أزرار الطباعة والتصدير والمشاركة والإرسال.

## ملاحظات

- «ترحيل» فُسّر تصديراً (حفظ PDF). إن كان المقصود ترحيلاً محاسبياً أو نقل العقد إلى نظام آخر فيحتاج طلباً منفصلاً.
- لا يُولَّد PDF على الخادم بعد، ولا يُرفق بالبريد تلقائياً. البريد وواتساب يرسلان رابط العقد وملخصه.
- قراءة بوابة المستأجر ما زالت تمر بـ Nest إن لم يكن للمستأجر طرف مرتبط في الجلسة.
