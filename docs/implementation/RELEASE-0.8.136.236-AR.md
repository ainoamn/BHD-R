# الإصدار 0.8.136.236 — تحديث بصري للوحتي المالك والمستأجر

**التاريخ:** 2026-11-18  
**النطاق:** `/[locale]/owner` و`/[locale]/tenant` (لوحة التحكم للمالك والعميل/المستأجر)

## الهدف

إعادة تصميم عصرية لواجهة التحكم المشتركة في بوابة المالك وبوابة العميل (tenant) دون المساس بالمسارات أو الصلاحيات أو واجهات API.

## ما تغيّر

- خلفية أوضح مع تدرّج هادئ وبطاقات شبه زجاجية للوحة الرئيسية.
- شريط علوي بخلفية ضبابية أوضح وحدود أنعم.
- شريط جانبي أعمق للمالك، ودرجة ذهبية أخف لمساحة المستأجر.
- تمييز أوضح للعنصر النشط في القائمة وروابط التبديل بين المساحات.
- حلقات الإحصاء وأزرار الشريط السريع بظلال وحدود أحدث.

## ما لم يتغيّر (متعمدًا)

- لا تعديل على منطق التنقل الناعم أو التخزين المؤقت أو الصلاحيات.
- لا تغيير على أسماء الـ CSS التي تعتمد عليها المكوّنات (`portal-nav`, `dash-shell`, …).
- لا تغيير على العقود أو APIs أو قاعدة البيانات.

## الملف المعدَّل

- `apps/web/src/app/portal-adaptive.css`

## التحقق

- Diff بصري فقط على CSS محمّل بعد `globals.css`.
- لا تغيير TypeScript؛ لا حاجة لإعادة توليد العقود.
