# الإصدار 0.3.3 — تنقل سلس للموقع العام (مثل لوحة التحكم)

**التاريخ:** 2026-08-31

## الطلب

تطبيق نفس أسلوب لوحة التحكم على [r.bhd-om.com](https://r.bhd-om.com/): عند فتح الموقع تُحمَّل الصفحات في الخلفية خفيفاً فيكون التنقل سلساً دون إثقال البيانات.

## التنفيذ

1. `MarketingRoutePrefetch`: تدفئة هياكل `/` و`/properties` و`/trust` و`/privacy` و`/terms` و`/accessibility` و`/portal`.
2. طلب كتالوج خفيف (`/api/public/catalogue?limit=8`) ثم prefetch لأول 6 صفحات عقار فقط (بدون تنزيل صور ثقيلة مسبقاً).
3. إزالة `properties/loading.tsx` التي كانت تفرّغ الشاشة أثناء الانتقال.
4. شريط تقدّم خفيف + روابط الهيدر بـ `scroll={false}`.

لا يعمل على مسارات البوابة (owner/…); تلك لها تدفئة مستقلة.
