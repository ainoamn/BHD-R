# الإصدار 0.8.134.139 — اكتمال البيانات وOTP البريد

**التاريخ:** 2026-10-25

## ما الجديد

- **تنبيهات الحقول الناقصة:** قواعد موحّدة للمالك والمستأجر (شخصي/شركة) والمبنى؛ تظهر في نموذج الحجز مباشرة وفي لوحة المالك.
- **مستندات وتواريخ انتهاء:** بطاقة/جواز/سجل تجاري مع النسخ وتواريخ الانتهاء؛ للمفوّضين حسب عماني/وافد وتوقيع منفرد أو متحد.
- **OTP البريد:** أثناء الحجز يُرسل رمز تحقق للبريد الإلكتروني للمستأجر أو الشركة (واتساب للجوال لاحقاً).

## أين تُختبر

1. حجز إيجار/شراء → بيانات الطرف: قائمة الحقول الناقصة، رفع النسخ، تواريخ الانتهاء، إرسال وتأكيد OTP.
2. لوحة المالك → تنبيه «بيانات المالك» و/أو «مبانٍ ناقصة» إن وُجدت.
