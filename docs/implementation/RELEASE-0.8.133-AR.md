# الإصدار 0.8.133 — بريد متجاوب وواتساب مرح باللغتين

**التاريخ:** 2026-10-20

## ماذا تغيّر

1. **تنسيق البريد** على كل الأجهزة (جوال / لوحي / سطح مكتب): إزالة `nowrap` الذي كان يقطع التفاصيل، صفوف مكدّسة (تسمية ثم قيمة)، حشو أوضح، زر بعرض الشاشة، وكسر كلمات آمن لـ Gmail وOutlook وتطبيقات الهاتف.
2. **رسائل واتساب** بنفس نبرة البريد: أيقونة النوع، ترحيب، تفاصيل، رابط، ثم أمنية مرحّة + عبارة تشجيعية تدور مع كل رسالة — بالعربية والإنجليزية.
3. **استوديو الإشعارات** (`/owner/notifications`): معاينة البريد بإطارات جهاز، وواتساب بفقاعتين AR/EN؛ زر خلط العبارة المرحّة يعمل للقناتين.
4. **دعوة الفريق** ومشاركة المحاسبة عبر واتساب تستخدمان المنسّق الجديد.

## أين تختبر

- `/ar/owner/notifications` — بدّل القالب والجهاز و«غيّر العبارة المرحّة».
- دعوة عضو من صفحة الفريق → نسخ / واتساب.
- إرسال فاتورة/قيد من المحاسبة عبر واتساب.
