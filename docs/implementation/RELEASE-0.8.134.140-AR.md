# الإصدار 0.8.134.140 — إعدادات عامة ولكل مبنى

**التاريخ:** 2026-10-26

## ما الجديد

- في **الضبط**: سياسة الاعتماد/التوقيع/المعاينة أصبحت بعنوان **إعدادات عامة — كل المباني**.
- أسفلها قسم **إعدادات خاصة لكل مبنى**: ابحث واختر مبنىً وعدّل مزيجاً مختلفاً (مثلاً حجوزات تلقائية، عقود يدوية، معاينات مؤتمتة) دون تغيير باقي المباني.
- المباني بلا تخصيص تبقى تتبع الإعدادات العامة؛ ويمكن الرجوع للعامة بزر «العودة».

## أين تُختبر

1. `/owner/settings` → عدّل الإعدادات العامة واحفظ.
2. اختر مبنىً من القائمة → غيّر نوع عقد واحد فقط → احفظ → تأكد أن شارة «مخصّص» تظهر.
3. احجز على ذلك المبنى وعلى مبنى آخر وتأكد من اختلاف السلوك.
