# الإصدار 0.4.29 — حالات التقويم + توحيد شكل ما بعد الحجز

**التاريخ:** 2026-09-02

## الملخص

- **التقويم:** كل يوم يعرض تسمية الحالة (شاغر / محجوز / مؤقت / مغلق) مع ألوان أوضح ودليل شارات أسفل التقويم.
- **الحجز:** خطوة الدفع وصفحة التأكيد بنفس أسلوب خطوات المراجعة (لوحة + ملخص + أزرار تنقّل).

## التفاصيل

### التقويم
- تسمية قصيرة داخل خلية اليوم: شاغر، محجوز، مؤقت، مغلق.
- ألوان مميزة: أخضر / أحمر / برتقالي / رمادي مخطّط للمغلق.
- دليل الحالات كشارات ملوّنة بنفس الأسماء الأربعة.

### ما بعد «تأكيد الحجز»
- لوحة ملخص موحّدة: مرجع، ضيف، تواريخ، مبلغ، حالة.
- أزرار بنفس صف التنقّل: ادفع الآن + عرض التأكيد.
- صفحة `/stays/booking/confirmed` بنفس أسلوب معالج الحجز.
