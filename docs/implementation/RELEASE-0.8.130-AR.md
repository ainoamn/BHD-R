# الإصدار 0.8.130 — زر فتح طلب المعاينة من جدول الحجوزات

**التاريخ:** 2026-10-19

## المطلوب

من `/ar/owner/bookings` كان صف المعاينة يظهر دون أي إجراء في عمود «الإجراءات»، فلا يمكن فتح الطلب للرد أو تحديد الموعد.

## السبب

شاشة الحجوزات الموحّدة (`PropertySectionRecords`) تبني رابط «فتح» للإقامات وحجوزات العربون فقط؛ صفوف `kind === 'viewing'` كانت تُرجع `null`.

## الحل

ربط المعاينة بـ `/{portal}/bookings/viewings/{id}` مع زر واضح «فتح المعاينة والرد».

لا ترحيل قاعدة بيانات.
