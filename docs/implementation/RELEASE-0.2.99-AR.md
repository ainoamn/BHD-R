# الإصدار 0.2.99 — تحميل كل صفحات البوابة في الخلفية

**التاريخ:** 2026-08-31

## الطلب

عند فتح الموقع، تحميل كل صفحات/أقسام بوابة المالك في الخلفية حتى لا يأخذ التنقل ~10 ثوانٍ.

## التنفيذ

1. عند أول فتح للبوابة: `router.prefetch` لكل روابط الشريط الجانبي.
2. طلب واحد `GET /api/portal/ops/:portal/warm` يعبّئ ذاكرة العميل بكل أقسام التشغيل دفعة واحدة.
3. تخزين مؤقت لصحة Nest (10 ثوانٍ) حتى لا يتكرر فحص cold-start لكل قسم.
4. إن فشل الـ batch: تراجع لتحميل الأقسام واحداً تلو الآخر.

## تحقق

ادخل بوابة المالك وانتظر بضع ثوانٍ دون تنقل، ثم تنقّل بين الأقسام — يفترض أن يظهر المحتوى من الذاكرة فوراً أو خلال أقل من ثانية.
