# الإصدار 0.3.4 — تصغير الواجهة الرئيسية وفلاتر العقارات

**التاريخ:** 2026-08-31

## الصفحة الرئيسية

تصغير قسم الـ hero (الارتفاع والعناوين) حتى تظهر خانة البحث والمحتوى التالي أبكر دون شغل معظم الشاشة.

## العقارات المتاحة

1. تبويب: الكل / عقار للإيجار / عقار للبيع  
2. فلاتر: المحافظة → الولاية → القرية/المنطقة  
3. نطاق السعر من–إلى (حسب الإيجار أو البيع حسب التبويب)  
4. مع نوع العقار وغرف النوم والعملة

البحث يعمل على Neon مع مطابقة أسماء المواقع عربي/إنجليزي.
