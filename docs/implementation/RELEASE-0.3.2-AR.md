# الإصدار 0.3.2 — إزالة وميض «أعد تسجيل الدخول»

**التاريخ:** 2026-08-31

## السبب

عند الرسم الفوري للقسم قبل وصول البيانات كان النظام يضع `apiOnline: false` فيظهر بانر:

«بعض الإجراءات غير متاحة مؤقتاً / أعد تسجيل الدخول…»

لمدة ثوانٍ ثم يختفي بعد اكتمال التحميل — والرسالة مضللة (ليست مشكلة جلسة).

## الإصلاح

1. الهيكل الفارغ أثناء التحميل لا يُظهر تحذير offline.
2. كتم بانرات الحالة حتى أول رد حقيقي للقسم.
3. قسم فارغ لأن Nest نائم لا يُعامل كـ «غير متصل» للمستخدم.
4. نص أوضح عند تعذّر الخدمة دون طلب إعادة تسجيل الدخول.

## تحقق

حدّث الصفحة على قسم مثل المحاماة — لا يظهر بانر أصفر لثلاث ثوانٍ ثم يختفي.
