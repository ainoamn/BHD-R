# الإصدار 0.2.94 — شارة واحدة + شعار مدمج + هيدر أوضح

**التاريخ:** 2026-08-31

## الإصلاحات

1. **شارة الإيجار:** إزالة العلامة المائية النصية المكررة على بطاقة العقار — تبقى شارة «متاح للإيجار» واحدة فقط.
2. **شعار عند التحميل:** `/api/public/media/:id` يدمج شعار BHD داخل بايتات الصورة (JPEG)، فيظهر عند «حفظ الصورة». كذلك Worker يدمج الشعار في المتغيرات الجديدة.
3. **هيدر البوابة:** إزالة تكرار «بوابة المالك»، وإخفاء شريحة المستخدم عند الضيق حتى لا تتداخل مع English.

## تحقق

- `/ar/properties` — شارة واحدة + شعار BHD على الصورة.
- حفظ الصورة من المعرض — الشعار داخل الملف.
- `/ar/owner/...` — الهيدر بدون تداخل نص English مع الاسم.
