## مبدأ القياس

متغيرات CSS على `:root` تتصغّر/تكبر مع العرض:

| متغير | دور |
|-------|-----|
| `--portal-pad` | حشو الصفحة والأقسام |
| `--portal-gap` | المسافات بين العناصر |
| `--portal-text` | حجم النص الأساسي |
| `--portal-title` | عناوين الصفحات |
| `--portal-control-h` | ارتفاع الحقول والأزرار |
| `--portal-icon` | أيقونات الهيدر (قائمة، لغة، حساب) |
| `--portal-radius` | انحناء البطاقات |

نقاط القطع:

| العرض | السلوك |
|------|--------|
| **≥961px** | جدول محفظة · شريط خطوات المعالج الكامل · ملخص 360 جانبي ثابت · هيدر كامل (عناوين + مستخدم + شبكة تطبيقات) |
| **≤960px** | بطاقات محفظة · شريط مراحل رفيع للمعالج · ملخص 360 أعلى المحتوى · إخفاء عناوين الهيدر/بطاقة المستخدم/شبكة التطبيقات · مقاييس 2×2 |
| **≤520px** | رموز أصغر وحقول أضيق وعناوين مختصرة |

## سلوك كل سطح

### قائمة العقارات
- سطح المكتب: `.ops-desktop-table`
- الجوال: `.ops-mobile-cards` (اسم، رقم متسلسل، مالك، موقع، حالة)
- لا تعتمد على تمرير أفقي للجدول على الهاتف

### المعالج (جديد / تعديل)
- سطح المكتب: `.wizard-progress--desktop` (7 خطوات مع تسميات)
- الجوال: `.wizard-progress-compact` (رقم المرحلة + اسمها + شريط رفيع)
- حقول أصغر؛ بعد اختيار قائمة منسدلة ينتقل التركيز للحقل التالي (وإن اكتملت المرحلة ينتقل للتالية)

### Property 360
- سطح المكتب: عمودان (محتوى + ملخص sticky)
- الجوال: عمود واحد؛ الملخص أولاً؛ معرض ومقاطع أوضح وأصغر

### الهيدر
- على الجوال: شعار + ☰ + رمز اللغة + أفاتار الحساب فقط (بدون تكرار بطاقة المستخدم وبدون شبكة التطبيقات)

## النشر

1. الدفع إلى `main` يشغّل نشر Vercel التلقائي لمشروع `bhd-r-api` (Root = `apps/web`).
2. بعد Ready: حدّث الصفحة بقوة على الجوال (أو امسح كاش المتصفح) لتجاوز CSS القديم.
3. تحقق بصري سريع:
   - قائمة: بطاقات ظاهرة وعدد النتائج يطابق القائمة
   - جديد/تعديل: لا دوائر خطوات كبيرة؛ حقول مضغوطة
   - 360: ملخص فوق المعرض على الهاتف؛ جانبي على الكمبيوتر
