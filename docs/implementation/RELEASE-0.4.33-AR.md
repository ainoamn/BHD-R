## الملخص

إعادة تصميم معالج إعداد الإقامة اليومية ليتوافق مع نموذج الفترات (بدون مبيت / مع مبيت):

1. **إزالة خطوة الوصف**: لا يُطلب وصف جديد — يُستخدم وصف العقار الحالي تلقائياً عند النشر.
2. **أوقات الدخول/الخروج حسب الفترة**: وقت الدخول، خروج بدون مبيت، خروج عند المبيت.
3. **سعة الضيوف حسب النوع**: حد للضيوف بدون مبيت وحد مع المبيت.
4. **السياسات والتعليمات**: قائمة سياسات قابلة للتحرير + تعليمات وصول، وتظهر في صفحة الإقامة العامة.
5. **الأسعار**: ثلاثة أنواع + مبلغ التأمين.
6. **الخطوات**: وحدات → سعة وسياسات → أسعار → مراجعة ونشر (4 خطوات).
