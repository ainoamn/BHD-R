# الإصدار 0.8.35 — إخفاء العقار بعد تأجيره أو بيعه بموافقة المالك، وبيانات العقار في الخطوة 3

**التاريخ:** 2026-10-13

## المطلوب

1. العقارات بالإيجار اليومي لا تُحذف بعد تأجيرها، وتبقى ظاهرة ما دامت معروضة للإيجار اليومي.
2. ما يُخفى هو العقارات المؤجّرة بعقود طويلة والمباعة فقط، وذلك **بعد موافقة المالك** على إخفائها.
3. بيانات العقار، مثل المدة ونوع الاستخدام، تظهر في الخطوة 3.

## ما تغيّر

### ظهور العقار بعد التأجير أو البيع

- **الإيجار اليومي:** لا يُخفى أبداً. صفحة `/stays` لا تُخفي وحدة بسبب حجوزاتها، وفي صفحة العقارات لا تُخفى وحدة نمطها يشمل `daily` مهما كان عليها، ولا يُسأل مالكها.
- **قبل قرار المالك:** الوحدة المؤجّرة بعقد طويل أو المباعة تبقى في صفحة العقارات بحالة «مؤجّر» أو «مباع»، ولا يمكن حجزها ولا طلب معاينتها. وتعرض صفحة الوحدة رسالة بذلك بدل أزرار الحجز.
- **الحجز المعتمد من المالك** لم يعد يُخفي العقار تلقائياً كما في 0.8.32. فالعقار يبقى بحالة «محجوز» مع تاريخ انتهاء الحجز.
- **سؤال المالك:** يظهر في الجرس وأعلى صفحة العقار:
  - وحدة للإيجار فقط أُجّرت، أو أي وحدة بيعت: «هل تريد إخفاءها من العقارات المعروضة؟». «نعم، أخفِها» تُخفيها، و«لا، أبقِها ظاهرة» تبقيها بحالتها.
  - وحدة للإيجار والبيع أُجّرت: السؤال السابق «هل ما زلت تريد بيعها؟». «نعم» تعرضها للبيع فقط ويمكن حجزها للشراء رغم الإيجار، و«لا» تحوّلها للإيجار فقط وتُخفيها.
- **ربط القرار بالعقد:** القرار مرتبط بالعقد أو البيع نفسه (`takenRef`). فإذا انتهى العقد أو أُلغي البيع عادت الوحدة للظهور تلقائياً، وإذا أُجّرت أو بيعت من جديد يُسأل المالك مرة أخرى.
- **الحجز من الخادم:** صار يرفض الوحدة المباعة. وحجز الشراء مسموح لوحدة مؤجّرة أبقاها المالك للبيع.

### بيانات العقار في الخطوة 3

- **صفحة الحجز** (`/book/{unitId}`)، الخطوة 3 «بيانات العقد»: بطاقة «بيانات العقار» تضم:
  - العقار ونوعه وموقعه ومساحته وغرفه وحماماته؛
  - نوع الاستخدام (سكني أو تجاري)؛
  - الإيجار الشهري أو سعر البيع؛
  - مدة العقد المختارة مع الحد الأدنى.
- **نوع الاستخدام الافتراضي** يتبع نوع العقار: المكتب والمحل والمستودع تجارية، والباقي سكني. ويستطيع العميل تغييره. وصار اسم الحقل «نوع الاستخدام (العقد)».
- **صفحة الحجز عند المالك**، المرحلة 3 (العقد والمستندات): بطاقة «بيانات العقار وطلب العميل» تضم:
  - الوحدة ومساحتها وسعرها؛
  - نوع الاستخدام ومدة العقد كما اختارهما العميل؛
  - المستأجر أو المشتري، فرداً كان أو شركة.

  والقيم نفسها مُعبّأة في نموذج العقد ويمكن تعديلها.

### الفحص الفعلي لصفحات المالك والمستأجر

انتهت صلاحية جلسة الدخول المحفوظة، فصارت الصفحات تُحوَّل إلى تسجيل الدخول، ولم يُكمَل الفحص. حُذف ملف الجلسة لأنه يحوي ملفات تعريف الدخول. ولإكماله بعد تسجيل الدخول، تُشغَّل الأوامر من `apps/web`:

```powershell
node scripts/responsive-audit.mjs login "$env:TEMP\bhd-state.json"
node scripts/responsive-audit.mjs run "$env:TEMP\bhd-audit-owner" --state "$env:TEMP\bhd-state.json" --crawl /ar/owner,/ar/tenant,/ar/guest --max 80
```

## التخزين

لا ترحيل لقاعدة البيانات. يُحفظ قرار المالك في `stay_policies` بالنوع `other` والرمز `listing_visibility:{unitId}`، مع إصدارات (السابق `archived`). وتحوي `rules_json` الحقول `takenRef` و`reason` (`leased` أو `sold`) و`hidden`. ويُسجَّل حدث في `workflow_events`، واحد من:

- `unit.listing_hidden`
- `unit.listing_kept`
- `unit.kept_for_sale`
- `unit.sale_withdrawn`
