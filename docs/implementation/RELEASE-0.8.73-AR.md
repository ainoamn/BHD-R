# الإصدار 0.8.73 — جلب المدفوعات الحقيقية + واجهة محاسبة أبسط

**التاريخ:** 2026-10-18  
**الحالة:** جاهز للرفع

## المشكلة

لوحة `/ar/owner/accounting` كانت تعرض أصفاراً رغم وجود مدفوعات إقامة وعربون: اللوحة كانت تقرأ فقط جداول `payments`/`invoices` (فارغة عند كثير من العملاء) وتتجاهل `stay_payment_intents` وعربون الحجوزات. ودليل الحسابات غير مهيأ تلقائياً. الواجهة كانت مزدحمة بسبع بطاقات متشابهة.

## الحل

1. **لوحة تعتمد على العمليات الفعلية:** المحصّل = فواتير + مدفوعات إقامة ناجحة؛ التأمينات = ودائع إقامات + عربون حجوزات مدفوعة.
2. **مزامنة إلى القيود:** `POST /api/owner/accounting/sync` يهيئ الدليل ويرحّل تاريخياً (إقامة / عربون / تأمين محتجز) بشكل idempotent.
3. **مزامنة تلقائية** عند أول فتح إذا لم يوجد دليل أو قيود مرحّلة؛ وزر «مزامنة المدفوعات».
4. **ترحيل فوري** عند تأكيد دفع إقامة sandbox.
5. **واجهة أبسط:** أربعة مؤشرات رئيسية، قائمة آخر التحصيلات، تبويبات أساسية أوضح، خلفية هادئة خضراء.

## التحقق
