# الإصدار 0.4.14 — تقييم / رفع صور / ترجمة / بطء قائمة العقارات

**التاريخ:** 2026-08-31  
**الأسطح:** صفحة عقار عامة، معالج إضافة/تعديل عقار، `/owner/properties`

## الظواهر

1. إرسال تقييم يظهر: «تعذّر حفظ التقييم. سجّل الدخول وحاول مجدداً» رغم تسجيل الدخول.
2. رفع الصور بعد حفظ العقار: `Failed to fetch` مع بانر أخضر وأحمر بنفس النص.
3. الترجمة المباشرة AR↔EN في التعديل لا تغيّر النص.
4. قائمة `/owner/properties` تتأخر طويلاً قبل ظهور الصفوف.

| # | السبب |

| 1 | `ReviewsPanel` استدعى `browserMutation` (مسارات Nest `/v1/...`) على `/api/public/reviews` فيفشل فوراً. |

## الإصلاح

- `browserNextMutation` لمسارات Next + CSRF من Vercel.
- رفع المالك عبر `/api/owner/media` → Neon/R2 فقط.
- إيقاف تسخين CSRF لـ Nest عند فتح المعالج؛ إبقاء `/api/warm` فقط.
- قائمة العمليات: السجلات أولاً، سياق بمهلة 1.8ث، تسخين `properties` أولاً.
