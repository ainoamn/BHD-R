# BHD R 0.4.70 — لوحة تحكّم المالك المدمجة

## المطلوب
تحسين `/ar/owner` (لوحة التحكم): تصغير أزرار/بطاقات الإحصائيات، توضيح جملة طريقة العرض، تحسين ترتيب الأقسام والتنبيهات.

## ما تغيّر
- إحصائيات مباشرة كشرائح صغيرة قابلة للنقر تنتقل للصفحة المرتبطة.
- جملة مقدمة أوضح تصف طريقة العرض (إحصائيات + تنبيهات مرتّبة + اختصارات).
- ترتيب الأقسام: ترحيب ← إحصائيات ← تنبيهات ← مالية/تنقّل سريع ← نشاط/إجراءات.
- تنبيهات مضغوطة مرتّبة حسب الأولوية (خطر → تحذير → معلومات) بنصوص أقصر.
- عرض كامل للوحة (`dash-shell` بدون سقف ضيق).

## اختبار
- [ ] `/ar/owner` بعد الدخول: الإحصائيات أصغر وفي صف مضغوط.
- [ ] النقر على مؤشر (مثل الوحدات الشاغرة) ينقل للقسم الصحيح.
- [ ] التنبيهات تظهر مرتّبة وتفتح الصفحة المناسبة.
- [ ] الاختصارات تشمل التقويم والحجوزات اليومية.
