# الإصدار 0.8.29 — صفحة حجز الإيجار أو الشراء عند المالك

**التاريخ:** 2026-10-12

## المشكلة

- فتح الحجز من جهة المالك (`/ar/owner/bookings/{id}`) يعرض «This page couldn’t load — A server error occurred».
- **السبب:** الصفحة كانت تطلب بياناتها من خدمة الـ API المنفصلة (`/v1/leasing/reservations/{id}/compliance`). وأي خطأ أو تأخر منها يُسقط الصفحة كلها.
- وحتى حين تعمل، كانت الصفحة قائمة مستندات فقط: حالة الحجز بالإنجليزية وجزء من المعرّف، دون العميل أو العربون أو الاتفاقية.

## الحل

- **حجز الموقع يُقرأ من قاعدة البيانات مباشرة** بالدالة `loadLeaseBookingForStaff`، دون الاعتماد على الـ API. وتعرض الصفحة:
  - **الرأس:** المرجع `RSV-…`، والعقار والوحدة، وزر «حجوزات العقار».
  - **تنبيه:** «دفع العميل العربون ووقّع اتفاقية الحجز. الوحدة محجوزة له حتى …؛ جهّز عقد الإيجار النهائي قبل ذلك».
  - **أربع بطاقات:**
    - الحالة («عربون مدفوع — جهّز العقد»)؛
    - العربون المدفوع ووقت الدفع؛
    - «محجوزة حتى» مع الإيجار الشهري أو سعر البيع؛
    - رقم التوقيع الإلكتروني بالأحمر ووقته.
  - **بيانات العميل:** الاسم، والهاتف (رابط اتصال)، والبريد، ومن حجز بالنيابة عنه إن وُجد، ووسيلة الدفع وآخر أربعة أرقام من البطاقة، ووقت قبول الشروط.
  - **اتفاقية الحجز الموقّعة** بتصميم العقد المعتمد نفسه، مع التوقيع ورقمه. وفوقها شريط الطباعة وPDF والمشاركة بالبريد والواتساب، ورابط المشاركة يفتح صفحة الاتفاقية عند العميل.
- **من يرى الصفحة:**
  - موظفو المنظمة نفسها ممن لديهم صلاحية `reservation.read`؛
  - المالك الفردي، لعقاراته فقط.
- **الحجوزات الأخرى** (غير حجوزات الموقع) تبقى على صفحة المستندات القديمة. وإن تعذّر الـ API تظهر رسالة «تعذّر تحميل ملف هذا الحجز الآن» مع زر العودة، بدل خطأ الخادم.

## الملفات
