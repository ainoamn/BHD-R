# إصدار 0.4.81 — إصلاح بطء التنقل (>120 ثانية)

**تاريخ:** 2026-09-11  
**المسارات:** `/ar` → `/properties` · `/units/[id]` · `/portal`

## السبب

استعلامات Neon على الكتالوج/الوحدة/نظرة البوابة كانت **بدون مهلة زمنية**، مع شفاء (heal) و`ALTER` في كل طلب، ومجمّع اتصالات `max: 1` — فيعلّق soft-nav دقائق. الصفحة الرئيسية وحدها كانت محمية بمهلة 8 ثوانٍ منذ 0.4.74.

## الإصلاح

| طبقة | تغيير |
| --- | --- |
| `/properties` | `withTimeout` 8 ث + `force-dynamic` |
| `/units/[id]` | `cache(getUnit)` + مهلات 6–8 ث |
| `/portal` overview | مهلة Neon 3 ث |
| كتالوج Neon | `statement_timeout=6s` + شفاء مرة/دقيقة كحد أقصى |
| مجمّع DB | `max: 3` للـ viewer/overview/listings |
| Prefetch تسويقي | تأخير `/properties` و`/portal` ووحدات التفاصيل |

## تحقق

بعد نشر Vercel: من `/ar` انتقل إلى العقارات/وحدة/البوابة — يجب أن تظهر خلال ثوانٍ قليلة (حتى لو Neon بطيء تُعرض صفحة فارغة/احتياطي بدل الانتظار دقيقتين).
