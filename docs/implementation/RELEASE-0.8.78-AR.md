# الإصدار 0.8.78 — ترويسة المحاسبة والتوقيع الإلكتروني + تعريب الواجهة

**التاريخ:** 2026-10-18

## المطلوب

1. أن تظهر القيود والفواتير والكشوفات بترويسة الشركة والتوقيع الإلكتروني كما في فواتير الإيجار (`/tenant/invoices/…?doc=invoice`).
2. أن تكون واجهة `/ar/owner/accounting` معرّبة وتعمل بالعربية والإنجليزية.

## الحل

- صفحة طباعة `/owner/accounting/print` تعرض مستنداً بترويسة (شعار، اسم عربي/إنجليزي، هاتف، سجل تجاري) وجداول وكتلة توقيع إلكتروني (QR + رمز + SHA-256) بنفس CSS فواتير الإيجار.
- التحقق العام: `/verify/accounting/[token]`.
- زر الطباعة يفتح صفحة الترويسة ثم «حفظ كـ PDF» من نافذة الطباعة.
- قاموس `accounting-hub-copy` للعناوين والتبويبات والنصوص الأساسية AR/EN.

لا ترحيل قاعدة بيانات.
