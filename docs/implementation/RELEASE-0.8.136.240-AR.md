# الإصدار 0.8.136.240 — لوحة مالك احترافية (Executive Dashboard)

**التاريخ:** 2026-11-18  
**النطاق:** `/[locale]/owner` (الرئيسية فقط)  
**المعاينة:** https://r.bhd-om.com/ar/owner

## الهدف

رفع مستوى رئيسية المالك من تخطيط بسيط إلى لوحة تحكم تنفيذية بأسلوب لوحات الإدارة الحديثة (مثل TailAdmin / Aniq UI): بطاقات KPI واضحة، مؤشرات دائرية، ولوحات منظمة للاعتمادات والتحصيل — دون تغيير المنطق أو الصلاحيات أو APIs.

## ما تغيّر

### التركيب البصري
- شريط ترحيب مضغوط مع التاريخ وأزرار الإجراءات (إضافة عقار / تقويم / تقارير).
- صف **KPI** بأربع بطاقات: الإشغال، الوحدات المشغولة، العقود السارية، التحصيل — كل بطاقة مع حلقة نسبة صغيرة.
- لوحة **مؤشرات المحفظة**: دائرة إشغال كبيرة + أسطورة (مشغول / شاغر / عقود) + شبكة حلقات للشاغر والمنتهي والمستأجرين والمتأخرات والصيانة والقضايا.
- لوحة **نبض الحسابات**: حلقة تحصيل + قيمة التحصيل + ملخص انتباه/متأخرات + اختصارات الفواتير والمدفوعات والمصروفات والمحاسبة.
- عمودان لـ **الاعتمادات** و**التنبيهات**.
- اختصارات التشغيل، رابط مساحة المستأجر عند الحاجة، وسجل النشاط القابل للطي.

### التقنية
- الصفحة تستخدم مجددًا `OwnerDashboard` بدل `PortalOverview` الكلاسيكي.
- طبقة CSS جديدة ضمن قسم `OWNER BOARD (obd-*)` في `portal-dashboard-modern.css`.
- نفس مصادر البيانات: `loadPortalOverview`، `loadViewerPendingApprovals`، `loadTenancySummary`.
- نفس قواعد `canOpenPortalPath` وروابط التنبيه/الاعتماد.

## ما لم يتغيّر (متعمدًا)

- لا تعديل على المسارات أو الصلاحيات أو APIs أو قاعدة البيانات.
- بوابات developer / platform / tenant تحتفظ بواجهاتها الحالية.
- منطق التنبيهات والاعتمادات والنشاط كما هو؛ التغيير بصري وتركيبي فقط.
