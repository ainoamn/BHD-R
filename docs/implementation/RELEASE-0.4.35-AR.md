# الإصدار 0.4.35 — سياسات/أسعار الإقامة + تقييمات ذكية بأسلوب Booking.com

**التاريخ:** 2026-09-02  
**الإنتاج:** https://r.bhd-om.com  
**صفحة الإقامة:** https://r.bhd-om.com/ar/stays/al-noor-building-a-01

## الملخص

1. **صفحة الإقامة** تعرض الآن: أوقات الفترات، مبالغ الإقامة (ثلاثة أنواع)، مبلغ التأمين، السياسات/الشروط، والتعليمات (أو نص توضيحي حتى تُثرى من تقييمات الضيوف).
2. **التقييم الذكي**: درجة `/10` تمزج تقييم الضيوف (80%) مع نسبة الإشغال لآخر 90 يوماً (20%).
3. **نظام تقييمات الإقامة** على `stay_reviews`:
   - إيجابيات / سلبيات
   - تقييمات تفصيلية (نظافة، موقع، قيمة، تواصل، دقة، دخول)
   - مسموح فقط بعد انتهاء الإقامة (خلال 90 يوماً) ولمالك الحجز
4. **واجهة بأسلوب Booking.com**: بطاقات «قيّم إقامتك» مع عدّاد الأيام المتبقية، وبطاقات التقييم المنشور مع درجة وتصنيف نصّي.
5. **مساعد ذكي**: توليد مسودة التقييم من الدرجات التفصيلية + كلمات مفتاحية.
6. **مزامنة**: نشر تقييم الإقامة يحدّث أيضاً تقييم العقار العام (`reviews`) ليظهر في شارة الدرجة.

## APIs

- `GET /api/public/stays/reviews?propertyId=`
- `GET /api/public/stays/reviews/pending`
- `POST /api/public/stays/reviews`
- `POST /api/public/stays/reviews/assist`
