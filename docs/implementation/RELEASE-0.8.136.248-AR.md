# الإصدار 0.8.136.248 — تنقل فوري في بوابة المالك

## المشكلة

عند التنقل بين أقسام بوابة المالك (لوحة التحكم، العقارات، الحجوزات، التأجير، المالية…) كان المحتوى يومض ويتأخر لأن اللوحة تُركَّب عند أول زيارة مع جلب بارد، وقائمة الحجوزات كانت تُفرَّغ أثناء التحديث، وتسخين الكاش كان يبدأ متأخراً وبالتسلسل.

## ما تغيّر

1. **Premount خامل** لكل أقسام العمليات المسموحة في `PortalMainSlot` (نفس أسلوب لوحة إدارة الموقع) — أول نقرة تقلب `hidden` فقط.
2. **تسخين أسرع:** انتظار أقصر ثم `warmAllOpsSections` دفعة واحدة، ثم ملء أي قسم بارد متبقٍ.
3. **الحجوزات:** لا تُمسح الصفوف أثناء إعادة الجلب؛ اللوحة تُمرَّر `active` وتُستورد بشكل ثابت بدل `dynamic`.
4. **لوحة التحكم:** تنقل ناعم (`pushState`) عند العودة من أقسام العمليات حتى لا يُعاد تحميل RSC كامل.

## التحقق

- من الرئيسية: افتح العقارات ثم الحجوزات ثم التأجير ثم الفواتير — يجب أن تظهر فوراً بلا وميض أبيض بعد ثوانٍ من أول تحميل للبوابة.
- أعد زيارة الحجوزات: القائمة تبقى ظاهرة أثناء أي تحديث خلفي.
