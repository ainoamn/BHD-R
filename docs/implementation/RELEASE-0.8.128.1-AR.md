# الإصدار 0.8.128.1 — إصلاح بناء بطاقة المعاينة على Vercel

**التاريخ:** 2026-10-19

## المطلوب

إعادة نشر الإنتاج بعد فشل بناء `bhd-r-api` على الالتزام 0.8.128.

## السبب

مسار إصدار بطاقة المعاينة كان يضيّق متغير `issuedPass` إلى `never` داخل الـ callback، فيفشل `tsc` أثناء `next build`.

## الحل

استخدام حامل كائن `{ pass }` بدل تعيين متغير محلّي من داخل المعاملة، حتى يبقى النوع سليماً بعد `await`.

لا ترحيل قاعدة بيانات إضافي.
