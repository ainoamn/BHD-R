# الإصدار 0.8.83 — تعريب المحاسبة + شيكات العقود + نوافذ الصرف/المشتريات

**التاريخ:** 2026-10-18

## المطلوب

1. تعريب كل نصوص نظام المحاسبة وظهورها بلغة الواجهة (عربي/إنجليزي).
2. جلب شيكات المستأجرين تلقائياً من عقود الإيجار المعتمدة.
3. زر يفتح نافذة منبثقة لإدخال صرف/دخل ومشتريات/مبيعات.

## الحل

- قاموس عرض للحالات والمصادر والعناوين المخزّنة؛ تتبدّل مع `locale`.
- عند فتح تبويب الشيكات تُزامَن جداول الشيكات من العقود الموقّعة/النشطة إلى سجل الشيكات.
- أزرار «إضافة صرف / دخل» و«إضافة مشتريات / مبيعات» تفتح نماذج منبثقة مثل قيد اليومية.

لا ترحيل قاعدة بيانات.
