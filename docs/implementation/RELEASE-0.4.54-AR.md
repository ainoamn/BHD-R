# الإصدار 0.4.54 — تصميم حجز منقسم + إصلاح عرض المراجعة

**التاريخ:** 2026-09-03  
**النطاق:** صفحة `/stays/[slug]/book` + واجهات التوافر/عرض السعر

## ما تغيّر

1. **التصميم:** صورة العقار في الجانب (يمين بالعربية مثل بطاقة ظفار في الدفع) وتفاصيل الحجز في اللوحة المقابلة — بدل النافذة المركزية فوق الخلفية.
2. **خطأ «تعذّر إكمال الحجز» في المراجعة:** الخادم يوسّع يوم بدون مبيت إلى نطاق حصري `[يوم، يوم+1)` حتى لو وصل `checkOut === checkIn`؛ لا يُرمى 500 من `nightsBetween`؛ عمود `lock_slot` يُفحص عبر `information_schema` دون إفشال المعاملة.
3. زر **إعادة المحاولة** في خطوة المراجعة إن فشل جلب العرض.

## تحقق سريع

- [ ] `/ar/stays/.../book` صورة يمين / نموذج يسار (سطح مكتب)
- [ ] day_use نفس اليوم → المراجعة تعرض السعر و«تأكيد الحجز» يتفعّل
- [ ] المتابعة إلى الدفع تعمل

## ملاحظة تشغيل

إن لم تُنفَّذ بعد `0023_stay_lock_slots.sql` على Neon، الحجز يعمل بدون أعمدة الفتحات (مسار آمن). يُفضَّل تطبيق الترحيل لتفعيل صباحي/مسائي معاً.
