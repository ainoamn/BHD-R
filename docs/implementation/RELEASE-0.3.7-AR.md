# الإصدار 0.3.7 — شريط بحث وتصفية بأسلوب Booking

**Vercel:** Production Ready — alias `r.bhd-om.com` (مثلاً `dpl_YfkDWJKT…`)

## ماذا تغيّر؟

إعادة تصميم كتالوج العقارات العامة بتجربة تصفية سريعة تشبه Booking.com، مع أداء أفضل عبر التصفية الفورية على العميل:

- شريط بحث ثابت (غرض الإيجار/البيع + نص + محافظة)
- شريط جانبي RTL: خريطة، ميزانية مع مدرج تكراري، مصفيات رائجة، مصفيات ذكية (لغة طبيعية)، نوع العقار مع العدادات، غرف/حمامات، موقع، مرافق
- على الجوال: درج تصفية + شريط سفلي (تصفية / خريطة)
- بطاقات نتائج أفقية (صورة + تفاصيل + سعر + CTA)
- العدادات تُحسب فوراً من كتالوج Neon المُثرى (مسبح، مواقف، مرافق)
- مزامنة الفلاتر مع عنوان URL للمشاركة

## حدود البيانات

لا نعرض حقول فنادق غير موجودة في النظام (إفطار، نجوم تقييم الضيوف، سياسة إلغاء Booking). المصفيات مربوطة بما في Neon: الغرض، الموقع، النوع، الغرف، السعر، المسبح، المواقف، رموز المرافق.

## تحقق سريع

1. افتح `/ar/properties` — يظهر الشريط الجانبي والنتائج (`props-browse` في HTML).
2. فعّل مصفاة (مثلاً فيلا أو مسبح) — تتحدث النتائج والعدادات دون إعادة تحميل كاملة.
3. صغّر الشاشة — زر «تصفية» يفتح الدرج؛ الشريط السفلي يظهر.
4. «اعرض على الخريطة» يفتح بحث OpenStreetMap حسب الموقع المختار.
