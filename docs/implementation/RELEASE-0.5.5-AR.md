# الإصدار 0.5.5 — صفحة الحجز: صورة أصغر وحقول أكبر

**التاريخ:** 2026-10-08
**الصفحة:** `/[locale]/stays/[slug]/book`

## الهدف

إعطاء نموذج الحجز المساحة الأكبر من الصفحة، وتكبير حقول التعبئة لتكون أسهل في القراءة والضغط، خصوصاً على الجوال.

## ما تغيّر

### صورة العقار (أصغر)

- **على الشاشات الكبيرة (1000px فأكثر):**
  - عمود الصورة أضيق: بين 19 و26rem بدل قرابة نصف الشاشة؛
  - ارتفاعها حتى 36rem بدل ملء الشاشة كاملة، وتبقى ثابتة أثناء التمرير.
- **على الجوال والأجهزة اللوحية:**
  - ارتفاع الصورة 15rem بدل 24rem، و13rem على الشاشات الأصغر من 600px بدل 21rem؛
  - على الشاشات الأصغر من 600px يُخفى شريط أوقات الوصول والمغادرة أسفل الصورة لتوفير المساحة.
- خط اسم العقار أصغر قليلاً ليتناسب مع الحجم الجديد.

### حقول التعبئة (أكبر)

| العنصر | قبل | بعد |
| --- | --- | --- |
| عرض بطاقة النموذج | 38–40rem | 46–48rem |
| ارتفاع الحقول والقوائم | 2.9rem | 3.4rem، والخط 1.05rem |
| عناوين الحقول | 0.8rem | 0.92rem |
| عناوين الأقسام | 0.82rem | 0.95rem |
| بطاقات نوع الإقامة | حشوة 0.75rem | حشوة 1rem، وأيقونة 3rem، وخطوط أكبر |
| حقلا الوصول والمغادرة | خط 1rem | خط 1.15rem وارتفاع 2.6rem |
| أزرار + / − للمدة | 2.3rem | 2.8rem |
| زر «متابعة» | 3.25rem | 3.6rem، والخط 1.1rem |

- المسافات بين الأقسام أوسع قليلاً (1.6rem).
- التعديل يشمل خطوات «بياناتك» و«المراجعة» لأنها تستخدم الأنماط نفسها.
