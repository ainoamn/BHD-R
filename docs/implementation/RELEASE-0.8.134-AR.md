# الإصدار 0.8.134 — معاينة أذكى، حارس أوضح، حجوزات أنظف

**التاريخ:** 2026-10-20

## ماذا تغيّر

1. **مكتب المعاينة:** اقتراحات ملاحظات مرحّة جاهزة بالعربي والإنجليزي، مع شريط ذكاء اصطناعي للترجمة والتصحيح وإعادة الصياغة قبل إشعار العميل.
2. **حارس المبنى:** لا يرى طلبات «مطلوب» قبل اعتماد الموعد من الإدارة؛ بعد التأكيد يصله بريد بالتفاصيل واسم المستخدم/الرمز ورابط بوابة المسح، وفي قائمة الحجوزات زر مسح/إدخال الرمز.
3. **شاشة الحجوزات:** أعمدة أقل أوضح ومنع تداخل النصوص والشارات.
4. **تذييل البريد وواتساب:** العربية والإنجليزية في أسطر منفصلة (التحيات، سبب الإرسال، الرسالة الآلية).
5. **التنقّل:** استوديو الإشعارات يبقى في الذاكرة عند التنقل بين أقسام البوابة بدون وميض إعادة تحميل.

## أين تختبر

- `/ar/owner/bookings/viewings/…` — اقتراحات + ترجمة.
- حساب حارس: الحجوزات قبل/بعد تأكيد الموعد.
- `/ar/owner/bookings` — عرض الجدول.
- `/ar/owner/notifications` — التنقّل من وإلى الحجوزات.
