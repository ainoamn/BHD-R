# الإصدار 0.6.6 — الوحدات الشاغرة كقائمة منسدلة، ونوافذ الإضافة على كامل الشاشة

**التاريخ:** 2026-10-11
**الصفحات:** `/[locale]/owner/bookings` (والمطوّر)، وصفحات المهام والصيانة والمحاماة والحسابات، وكل النوافذ المنبثقة في لوحة العمليات

## المشكلة

- كان قسم «وحدات شاغرة — إجراءات سريعة» يعرض كل الوحدات الشاغرة مفتوحة فوق الجدول، فيأخذ مساحة كبيرة.
- عند الضغط على «＋ حجز جديد» كانت النافذة المنبثقة تظهر أسفل الصفحة بدل أن تغطي الشاشة.
  - **السبب:** حاوية لوحة العمليات `.portal-ops-pane` عليها حركة دخول تستخدم `transform`.
  - في المتصفح، العنصر الذي عليه `transform` يصبح المرجع لأي عنصر `position: fixed` بداخله.
  - لذلك كانت النافذة تتموضع داخل الصفحة وليس على الشاشة.

## الحل

### 1. الوحدات الشاغرة كقائمة منسدلة

- القسم أصبح عنصر `<details>` مطوياً افتراضياً.
- يظهر سطر واحد فيه العنوان والوصف، وشارة بعدد الوحدات (مثل «14 وحدة») وسهم.
- عند الفتح تظهر كل الوحدات مع أزرار «حجز / مهمة / صيانة / محاماة / حسابات».
- القائمة المفتوحة بارتفاع أقصى، ولها تمرير داخلي إذا طالت.
- على الجوال يُخفى الوصف ويبقى العنوان والعدد.

### 2. النوافذ المنبثقة على كامل الشاشة ومتجاوبة

- مكوّن جديد `ModalPortal`:
  - يعرض النافذة مباشرة داخل `<body>` عبر `createPortal`، فلا تؤثر عليها حاويات الصفحة.
  - يمنع تمرير الصفحة خلف النافذة أثناء فتحها.
  - يغلق نافذة الحجز الجديد ونافذة تجديد العقد بزر Escape.
- طُبّق على كل نوافذ لوحة العمليات:
  - إضافة سجل جديد (منها «حجز جديد»).
  - تفاصيل الحركة المحاسبية.
  - تجديد العقد.
  - إلغاء مفتاح API.
- التصميم:
  - خلفية معتمة تغطي الشاشة كاملة.
  - **الكمبيوتر:** النافذة في الوسط وبعرض أقصى 64rem. نافذة الإضافة بارتفاع الشاشة كاملاً.
  - **الجوال والتابلت (حتى 900px):** النافذة تملأ الشاشة كاملة بلا حواف.
  - رأس النافذة (العنوان وزر الإغلاق ×) ثابت بالأعلى.
  - أزرار «إلغاء / حفظ» ثابتة بالأسفل، والحقول تتمرر بينهما.
  - على الشاشات الضيقة (حتى 520px) يأخذ الزرّان نصف العرض لكل منهما.
  - مراعاة حواف الشاشات ذات النتوء (`safe-area-inset`).
  - حركة ظهور خفيفة تُلغى لمن يفضّل تقليل الحركة.

## الملفات

- `apps/web/src/components/modal-portal.tsx` (جديد): النقل إلى `<body>`، ومنع التمرير، والإغلاق بـ Escape.
- `apps/web/src/components/operations-console.tsx`:
  - تغليف النوافذ الأربع بـ `ModalPortal`.

  - تحويل `ops-vacant-strip` إلى `<details>` مع `summary` وعدد وسهم، وعرض كل الوحدات بدل أول 12.
- `apps/web/src/app/globals.css`: قسمان في آخر الملف، «Vacant units — collapsed dropdown» و«Operations modals — full-screen overlay».
