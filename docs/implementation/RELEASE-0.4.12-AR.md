# الإصدار 0.4.12 — إصلاح CSRF المحفظة + الأرشيف + الحذف النهائي

**التاريخ:** 2026-08-31  
**مرجع التحليل:** [`KNOWN-ISSUES-PROPERTY-PORTFOLIO-AR.md`](./KNOWN-ISSUES-PROPERTY-PORTFOLIO-AR.md)

## ماذا أُصلح؟

- فصل CSRF: `browserMutation` ← Nest؛ `/api/owner/*` ← Next مع إعادة سكّ وإعادة محاولة 403.
- استعادة/أرشفة/حذف نهائي عبر Neon: `POST /api/owner/properties/:id/lifecycle`.
- قائمة العقارات تستبعد المؤرشف؛ زر «الأرشيف» يحمّل `?view=archive`.
- زر حذف نهائي على العقار المؤرشف (مرفوض إن وُجدت عقود أو ملف إقامة).

## تحقق

إضافة عقار + أرشفة + استعادة + عرض الأرشيف + حذف نهائي (عقار بلا عقود).
