# الإصدار 0.4.97 — إعادة تصميم صفحة إدارة العقار

الصفحة: `/owner/properties/[propertyId]` و`/developer/properties/[propertyId]` (المكوّن `PropertyManageHub`).

## الهدف

صفحة جذابة وراقية وبسيطة، والمعلومات فيها مرتبة، وشريط «إجراءات هذا العقار» ظاهر دائماً في الأعلى.

## شريط الإجراءات الثابت في الأعلى

- أول عنصر في الصفحة، ويبقى ثابتاً أسفل رأس البوابة مباشرة عند التمرير (`position: sticky`).
- ارتفاع رأس البوابة يُقاس تلقائياً (`ResizeObserver`) ويُضبط في المتغير `--pmh-sticky-top`، فيعمل الشريط بنفس الشكل على الكمبيوتر والجوال.
- يحتوي: زر الرجوع للمحفظة، اسم العقار، ثم الإجراءات بأيقونات:
  - تعديل العقار (الزر الرئيسي)؛
  - عرض للجمهور؛
  - الإقامة اليومية (عند تفعيلها)؛
  - الحجوزات والمعاينات؛
  - العقود؛
  - الشروط والأحكام؛
  - التأجير؛
  - البيع؛
  - الصيانة؛
  - الفواتير؛
  - الحسابات.
- على الجوال يُخفى اسم العقار، وتُسحب الإجراءات أفقياً.

## ترتيب الصفحة

1. **بطاقة العقار الرئيسية:** صورة الغلاف (أو زر «أضف صور العقار» إن لم توجد صور)، وحالة العقار بالعربية (نشط / مسودة / غير نشط / مؤرشف)، والنوع، والرقم المتسلسل، والاسم، والعنوان. وتحتها معلومات سريعة: المالك، عربون الحجز (أو «غير محدد»)، المساحة، سنة البناء.
2. **أرقام سريعة:** الوحدات (مع عدد المنشورة)، الإقامات النشطة، العقود والإيجارات، الصور.
3. **عمودان:**
   - الرئيسي:
     - الحجوزات اليومية: المرجع، الضيف، الوحدة، التواريخ، المبلغ، الحالة؛
     - العقود والإيجارات، مع حالات بالعربية؛
     - **الوحدات (جديد):** لكل وحدة اسمها ورمزها، الغرف والحمامات والمساحة، السعر ونوع العرض، الإشغال، ومنشورة أو غير منشورة.
   - الجانبي:
     - «يحتاج انتباهك»: التنبيهات بلون مميز، وكل تنبيه رابط إلى مكان الإصلاح، أو «كل شيء جاهز» إن لم توجد تنبيهات؛
     - المالية: المحصّل من الإقامات اليومية، المحصّل من فواتير الإيجار، الفواتير المفتوحة، وآخر المدفوعات.
4. **إجراءات حساسة** في الأسفل: الأرشفة أو الاستعادة، والحذف النهائي للعقار المؤرشف. السلوك نفسه دون تغيير.
