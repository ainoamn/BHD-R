# إصدار 0.4.79 — أساس مزامنة Hisaby

**تاريخ:** 2026-09-09  
**الهدف:** تمكين صلاحيات قراءة كاملة لـ Hisaby + ربط تلقائي لدفع الأحداث بعد لصق رمز Hisaby.

## ما تغيّر في BHD-R

1. **صلاحيات مفتاح API:** تعبئة «Hisaby قراءة» تشمل عقارات، عناوين، أطراف، عقود، إيجارات، فواتير، مدفوعات، إيصالات، حسابات/قيود/مصروفات، حجوزات إقامة، تقارير…
2. **تصدير سحب:** `GET /v1/integrations/hisaby/export` — لقطة حسب صلاحيات المفتاح.
3. **ربط دفع تلقائي:** على `/ar/owner/api-keys` — لصق `eventsUrl` + رمز وارد من Hisaby → يُحفظ مشفّراً في `hisaby_links`.
4. **Worker:** عند أحداث مالية/إقامة يدفع JSON إلى نقطة Hisaby تلقائياً (بدون تدخل بشري بعد الربط).

## شرط اكتمال المزامنة الحيّة

Hisaby يجب أن يوفّر:
- إنشاء رمز وارد
- `POST /api/integrations/bhd-r/events` (أو المسار النهائي على `hisaby.bhd-om.com`)

حتى ذلك الحين: الحفظ والاختبار جاهزان في BHD-R؛ الدفع ينتظر استجابة Hisaby الناجحة.

## اختبار سريع

1. `/ar/owner/api-keys` → تعبئة صلاحيات Hisaby → إنشاء مفتاح.
2. لصق رابط أحداث Hisaby + الرمز → حفظ الربط.
3. بعد جاهزية Hisaby: «اختبار الاتصال».
4. دفع إقامة تجريبي → يُفترض ظهور حدث في Hisaby.
