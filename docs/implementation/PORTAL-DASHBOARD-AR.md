# لوحة التحكم ورفع مستوى صفحات البوابة (0.2.22)

## الهدف

رفع **لوحة التحكم** وجميع أقسام التشغيل (المعاملات، المالية، التشغيل، المنظمة) إلى مستوى بصري قريب من معالج إضافة العقار: بطاقات زجاجية، شريط ألوان قوس قزح، مقاييس واضحة، وتنبيهات قابلة للنقر.

## لوحة التحكم (`PortalOverview`)

المسار: `/{portal}` عبر `apps/web/src/components/portal-overview.tsx`.

| قسم | المحتوى |
| --- | --- |
| Hero | ترحيب، آخر تحديث من الـ API، اختصارات إضافة عقار / تقارير |
| تنبيهات | صيانة مفتوحة، عقود قاربت الانتهاء، فواتير معلّقة، وحدات شاغرة |
| إحصائيات مباشرة | إشغال، عقارات، وحدات، عقود سارية، شاغرة، تذاكر، عقود منتهية، فواتير |
| نبض المالية | التحصيل + روابط فواتير / مدفوعات / مصروفات |
| اختصارات + نشاط | روابط سريعة وآخر أحداث سير العمل |

### API

`GET /v1/{portal}/overview` في `organizationOverview` (`apps/api/src/portals/portals.service.ts`) يعيد أيضاً:

- `properties`, `units`, `activeLeases`, `vacantUnits`, `openInvoices`
- `alerts[]` (`severity` + `code` + `count`)
- `generatedAt` (ISO)

نطاق المالك (`ownerPartyId`) يُطبَّق على العقارات والوحدات والعقود والفواتير والصيانة عند الاقتضاء.

## أقسام التشغيل المشتركة

معظم قوائم المالك/المطور تمر عبر `OperationsConsole`:

- رأس الصفحة بنفس أسلوب الـ hero الزجاجي + شريط قوس قزح
- مقاييس بأشرطة علوية ملوّنة
- لوحة جدول، شريط بحث دائري، أزرار إجراءات، ومراحل سير عمل محدثة

الملف: `apps/web/src/components/operations-console.tsx` + أنماط `.ops-*` و `.dash-*` في `globals.css`.

## التحقق بعد النشر

1. افتح `/ar/owner` وتحقق من ظهور المقاييس والتنبيهات ووقت التحديث.
2. افتح قسماً مثل `/ar/owner/contacts` أو `/ar/owner/invoices` وتأكد من الرأس والجدول.
3. إن كانت الأرقام صفراً مع وجود بيانات: تأكد أن Nest على Render محدّث وأن `API_INTERNAL_ORIGIN` على Vercel يشير إليه.
