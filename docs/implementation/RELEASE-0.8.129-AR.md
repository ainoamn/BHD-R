# الإصدار 0.8.129 — تسريع صفحة الحجوزات للمالك

**التاريخ:** 2026-10-19

## المطلوب

ظهور بيانات `/ar/owner/bookings` خلال جزء من الثانية بدل انتظار طويل.

## السبب

1. الصفحة كانت تنتظر سياق النماذج الثقيل (وحدات شاغرة / أطراف) حتى ~1.8 ثانية.
2. مالكو المباني مرّوا بمسار `loadAllPropertyBookings` الثقيل مع شارات السجلات.

## الحل

- مسار Neon مباشر للحجوزات مع فلترة `ownerPartyId` عند الحاجة.
- ميزانية سياق قصيرة (350ms) لصفحة الحجوزات حتى لا تُحجب القائمة.
- تسخين قسم الحجوزات أولاً في ترتيب الـ warm.
- حد صفوف أوضح (120) لقائمة الحجوزات.

لا ترحيل قاعدة بيانات.
