# إصدار 0.4.84 — محفظة المالك + خروج بدون وميض

**تاريخ:** 2026-09-11

## 1) `/ar/owner/properties` بطيء أو فارغ

**السبب:** استعلام Neon للعقارات بلا مهلة + صور وحدات لكل عقار؛ عند الفشل كان الواجهة تعرض «لا توجد سجلات» كأنها محفظة فارغة.

**الإصلاح:**
- `statement_timeout=6s` لكل معاملات ops
- سقف 7 ثوانٍ لمسار العقارات
- تخفيف استعلام الغلاف (بدون fan-out صور الوحدات)
- حالة تحميل / خطأ + زر إعادة محاولة
- تسخين الأقسام أهدأ بعد تحميل العقارات

## 2) وميض الشاشات عند تسجيل الخروج

**السبب:** العودة إلى `https://r.bhd-om.com/` ثم إعادة توجيه next-intl إلى `/ar`.

**الإصلاح:** وجهة ما بعد الخروج الافتراضية = `/{locale}` و`BHD_OAUTH_POST_LOGOUT_REDIRECT_URI=https://r.bhd-om.com/ar`.

### مطلوب يدوياً على Identity

في عميل `bhd-r` على https://id.bhd-om.com أضف post-logout URI:

- `https://r.bhd-om.com/ar`
- (اختياري) `https://r.bhd-om.com/en`

وحدّث متغير Vercel `BHD_OAUTH_POST_LOGOUT_REDIRECT_URI` إلى نفس القيمة.
