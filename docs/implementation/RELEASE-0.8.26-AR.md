# الإصدار 0.8.26 — صفحتا الحجز بروح صفحة الإقامة

**التاريخ:** 2026-10-12

## المشكلة

- صفحة إقامة الضيف (`/guest/stays/{id}`) تستقبل الضيف بمشهد مرسوم لكل مرحلة وكلام ترحيبي دافئ.
- صفحتا الحجز نفسيهما جافتان: نموذج وخطوات فقط، دون صورة أو كلمة طيبة. وهما:
  - **حجز الإقامة اليومية:** `/stays/{slug}/book`.
  - **حجز الإيجار أو الشراء بمبلغ ضمان:** `/book/{unitId}?mode=rent`.

## الحل

- **مشهد مرسوم لكل خطوة** تحت شريط الخطوات، بأسلوب صفحة الإقامة نفسه: الضيف بالدشداشة والكمة، وبيت المالك بعلم عُمان، والنخيل والشمس. وشاشة جوال الضيف مكبَّرة تُظهر الخطوة الحالية:

  | الخطوة                   | ما تُظهره الشاشة                                                 |
  | ------------------------ | ---------------------------------------------------------------- |
  | الإقامة                  | تقويم يُختار فيه يوما الوصول والمغادرة، ثم الضيوف والنهار والليل |
  | الشروط (الإيجار والشراء) | صفحة العقد، ثم التوقيع يُرسم، ثم الختم                           |
  | بياناتك                  | بطاقة الضيف تُكتب سطورها، ثم علامة صح                            |
  | المراجعة                 | ثلاثة بنود تُعلَّم واحداً بعد الآخر، والعدسة تمر عليها           |
  | الدفع                    | البطاقة، والقفل يُغلق، وقطعة نقدية تطير إلى بيت المالك           |
  - في كل مشهد يضغط الضيف زر الشاشة فتطير الرسالة إلى بيت المالك وتظهر علامة صح عليه.
  - تحت المشهد لوحة فيها اسم الخطوة ورقمها (مثل 1 / 4) وحالة مرحة («نختار أجمل الأيام»، «نقرأ الشروط معاً»)، وزر «شاهد مجدداً».

- **ترحيب لكل خطوة باسم الضيف** في بطاقة بأسلوب صفحة الإقامة. أمثلة:
  - «أهلاً بك في مبنى النور! لنرتّب إقامتك على ذوقك».
  - «تشرّفنا يا Abdul! عرّفنا بنفسك».
  - «لحظة تدقيق قبل الانطلاق».
  - «حجزك محفوظ! بقيت خطوة واحدة».
  - في الإيجار والشراء: «أهلاً يا Abdul! خطوتك الأولى نحو بيتك الجديد»، و«مبروك! بقي دفع مبلغ الضمان».
  - يُستعمل الاسم الأول فقط، والاسم اللاتيني بحروف كبيرة يُكتب بحرف كبير أول (ABDUL ← Abdul). والاسم المؤقت «مستخدم BHD» لا يُنادى به.
- **لوحة صفحة الإيجار الجانبية بصياغة أدفأ:**
  - العنوان: «بيتك القادم على بُعد أربع خطوات» (أو «عقارك القادم» في الشراء).
  - المقدمة: «خطوات بسيطة وواضحة، ونحن معك في كل واحدة منها».
  - الخطوات الأربع بصيغة المخاطب، وآخرها «ثم تستلم المفاتيح».
- **الحركة الهادئة:** إن طلب الجهاز تقليل الحركة، يظهر المشهد مكتملاً دون حركة.

## التحقق

- `tsc` نظيف، واختبارا `booking-step-greeting` ينجحان.
- ESLint نظيف على الملفات الجديدة. وخطآ `@next/next/no-img-element` في صفحة `/book` سابقان، من تعليقين قديمين لم يتغيرا.
- **على فرع Neon من قاعدة الإنتاج:**
  - صفحة حجز «مبنى النور» اليومية: مشهد التقويم والترحيب في الخطوة الأولى، ثم بطاقة الضيف، ثم المراجعة.
  - صفحة `/book/90cd9d0b-…?mode=rent` بجلسة تجريبية: مشهد الشروط مع «أهلاً يا Abdul! خطوتك الأولى نحو بيتك الجديد».
  - المشاهد الخمسة صُوّرت معاً في صفحة معاينة مؤقتة حُذفت بعد ذلك.
  - على عرض الجوال (390 بكسل) يظهر المشهد كاملاً دون تمرير أفقي.
