# الإصدار 0.3.8 — خريطة ذكية + اكتشاف + تقييمات

**التاريخ:** 2026-08-31  
**الصفحات:** https://r.bhd-om.com/ar/properties · صفحة العقار · `/ar/parties/[id]`

## ماذا تغيّر؟

1. **قائمة بأسلوب Booking** مع شارة التقييم وزر «عرض التوافر».
2. **اعرض على الخريطة:** لوحة تفاعلية (Leaflet/OSM) بدبابيس من إحداثيات/روابط الخرائط المخزّنة في النظام؛ النقر يزامن القائمة.
3. **صفحة العقار:** علامات ذكية، عقارات مشابهة، مقترحة، الأعلى تقييماً.
4. **تقييمات وتعليقات:** عقار / مالك (طرف) / مؤسسة — لأي مستخدم مسجّل؛ شارة مستأجر سابق / مشتري / مالك موثّق عند وجود عقد أو صفقة؛ المالك يقيّم المستأجر عبر ملف الطرف.
5. هجرة Neon: جدول `reviews` + سياسات RLS.

## تحقق

1. `/ar/properties` → تصفية → «اعرض على الخريطة» تظهر الدبابيس.
2. صفحة عقار → أقسام الاكتشاف + نموذج التقييم بعد تسجيل الدخول.
3. `/ar/parties/{ownerPartyId}` → ملخص التقييمات.
