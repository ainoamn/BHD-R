## ماذا تغيّر؟

1. **قائمة بأسلوب Booking** مع شارة التقييم وزر «عرض التوافر».
2. **اعرض على الخريطة:** لوحة تفاعلية (Leaflet/OSM) بدبابيس من إحداثيات/روابط الخرائط المخزّنة؛ النقر يزامن القائمة.
3. **صفحة العقار:** علامات ذكية، عقارات مشابهة، مقترحة، الأعلى تقييماً؛ رابط عام لملف المالك.
4. **تقييمات وتعليقات:** عقار / مالك (طرف) / مؤسسة — لأي مستخدم مسجّل؛ شارة مستأجر سابق / مشتري / مالك موثّق؛ المالك يقيّم المستأجر عبر `/ar/parties/{id}`.
5. هجرة Neon: جدول `reviews` + سياسات RLS (`0014_reviews.sql`).

## تحقق يدوي سريع

1. `/ar/properties` → تصفية → «اعرض على الخريطة» تظهر الدبابيس.
2. صفحة عقار → أقسام الاكتشاف + نموذج التقييم بعد تسجيل الدخول → رابط المالك.
3. `/ar/parties/{ownerPartyId}` → ملخص التقييمات (ومالك يقيّم مستأجراً من نفس الصفحة إن وُجد طرف).
