# BHD R 0.4.71 — نبض العقار + تخصيص العرض

## المطلوب
- بعد الدفع والحجز تظهر الحجوزات/العقود/المالية على صفحة العقار للمالك.
- تخصيص العقار من البداية: بيع / شهري / سنوي / يومي.
- اليومي فقط لا يظهر في كتالوج `/properties`.
- انعكاس المدفوعات في صفحة العقار وفي `/owner/accounting`.

## لماذا لم تكن تظهر سابقاً؟
صفحة `/owner/properties/[id]` كانت `PropertyManageHub` بروابط فقط، بدون قراءة `stay_bookings` أو العقود أو المدفوعات.

## ما تغيّر
- محمّل `loadPropertyOpsPulseOnNeon` + بطاقات على صفحة إدارة العقار.
- حقل `units.offering_modes` (best-effort ALTER) وأوضاع في معالج الإنشاء/التعديل.
- استبعاد الوحدات اليومية فقط من كتالوج `/properties`.
- دمج مدفوعات الإقامة الناجحة في مساحة الحسابات.

## اختبار
- [ ] بعد حجز يومي مدفوع: يظهر في `/ar/owner/properties/{id}` وفي المالية.
- [ ] وحدة «يومي فقط» لا تظهر في `/ar/properties`.
- [ ] `/ar/owner/accounting` يعرض مدفوعات الإقامة عند توفرها.
- [ ] إنشاء عقار جديد بأوضاع متعددة يحفظ التخصيص.
