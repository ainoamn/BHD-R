# الإصدار 0.4.30 — تقويم أخضر + تسعير يومي + ملاحظات للجمهور

**التاريخ:** 2026-09-02

## الملخص

- الأيام بلا سجلات مخزون تُعرض **شاغرة خضراء** مع السعر الأساسي (بدل رمادي «غير متاح»).
- المالك يضبط **إيجار يوم معيّن** (رفع/تخفيض) و**ملاحظة عامة** (تهنئة / سبب العرض) من تقويم التشغيل.
- السعر والملاحظة يظهران في التقويم العام؛ الحجز يحسب السعر حسب أسعار الأيام.

## تفاصيل

### إصلاح العرض
- `fillInventoryCalendarDays` → الافتراضي `available` + سعر أساسي من خطة الأسعار.

### قاعدة البيانات
- `stay_inventory_days.public_note`
- `stay_inventory_days.manual_rate` (يحفظ السعر المخصّص عند إعادة بناء المخزون)

### واجهات
- عام: سعر تحت رقم اليوم + أيقونة ملاحظة
- مالك: `/owner/stays/calendar` — اضغط يوماً → سعر / ملاحظة / إغلاق
- API: `POST /api/owner/stays/day-override` و `POST /v1/stays/units/:unitId/inventory-days`
