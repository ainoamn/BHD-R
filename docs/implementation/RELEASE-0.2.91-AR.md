# الإصدار 0.2.91 — حقول الوحدة (مجالس / صالات / مطابخ / مسبح)

**التاريخ:** 2026-08-31

## ماذا تغيّر

في خطوة **الوحدات** بمعالج إنشاء/تعديل العقار (`/owner/properties/new` و`…/edit`):

| الحقل | التخزين |
| --- | --- |
| عدد المجالس | `units.majlis` |
| عدد الصالات | `units.halls` |
| المطابخ | `units.kitchens` |
| حوض سباحة (متوفر / غير متوفر) | `units.has_pool` |

- عقود Zod + Nest + Neon create/update/load.
- هجرة `0013_unit_room_counts` (طُبّقت على Neon الإنتاج).

## تحقق سريع

1. افتح [إضافة عقار](https://r.bhd-om.com/ar/owner/properties/new) → الخطوة 2 (الوحدات).
2. تأكد من القوائم الأربعة بعد الحمامات.
3. احفظ عقاراً تجريبياً وافتح التعديل وتحقق أن القيم تعود.
