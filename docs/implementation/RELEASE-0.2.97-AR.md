# الإصدار 0.2.97 — تسريع التنقل (20–160 ثانية)

**التاريخ:** 2026-08-31

## السبب

1. القائمة الجانبية كانت تُحمّل مسبقاً (~20 مسار) دفعة واحدة → توقظ Nest على Render Free فيتعلّق كل شيء.
2. طلبات بدون مهلة (`/v1/me`، ops، warm حتى 55 ثانية).
3. الصفحة الرئيسية تستدعي Nest حتى عندما Neon يردّ فارغاً بنجاح.

## الإصلاح

- `prefetch={false}` في شريط البوابة.
- Prefetch خامل محدود ومتسلسل (4 صفحات + قسمين ops).
- مهلات قصيرة: me 2.5s، ops 6s، warm 8s، Nest API 4s.
- عدم الرجوع لـ Nest للكتالوج إذا Neon نجح.
- `getViewer` يتسابق مع DB خلال 1.8s.

## تحقق

حدّث بقوة ثم تنقّل بين العقارات / لوحة المالك — يفترض ثوانٍ لا عشرات الثواني.
