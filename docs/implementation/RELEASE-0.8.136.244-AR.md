# الإصدار 0.8.136.244 — شريط أخضر + جداول بأسلوب السجلات الحكومية

**التاريخ:** 2026-11-18  
**النطاق:** كامل بوابة المالك والمستأجر (قوائم، جداول، حقول منبثقة)

## المطلوب

1. إرجاع الشريط العلوي من البرتقالي إلى الأخضر السابق.
2. الإبقاء على الهيكل الفاتح البسيط.
3. ضبط الصفحات الداخلية لتطابق أسلوب لقطات سجلات وزارة العمل: رأس جدول كحلي، صف بحث تحت الأعمدة، شارات حالة ملونة، نوافذ منبثقة مرتبة.

## ما طُبّق

- `--pd-topbar: #0d7a6d` للمالك (أزرق داكن للمستأجر).
- رؤوس الجداول `#1e3a5f` بنص أبيض في `ops-table` / `data-table` / جداول المحاسبة.
- صفوف متناوبة خفيفة، hover أزرق فاتح.
- شارات الحالة: أخضر نشط، ذهبي تحذير، أزرق معلومات، أحمر خطر.
- شريط الأدوات/التصفية خلفية `#f3f6f9`.
- النوافذ المنبثقة: رأس كحلي، جسم أبيض، تذييل أزرار رمادي فاتح.
- مجموعات القائمة الجانبية كعناوين أكورديون فاتحة.
- الأزرار الأساسية خضراء (هوية BHD) بدل البرتقالي.

## التحقق

- [ ] الشريط العلوي أخضر وليس برتقالي.
- [ ] العقارات/التأجير/الفواتير: رأس جدول كحلي + فلاتر تحت الأعمدة إن وُجدت.
- [ ] شارات الحالة ملونة وصلبة.
- [ ] نافذة «إضافة»/إنشاء: رأس كحلي وحقول مرتبة.
- [ ] القائمة الجانبية فاتحة والمجموعات واضحة.
