# الإصدار 0.2.98 — إصلاح «جاري تحميل القسم» وتنقل بوابة المالك

**التاريخ:** 2026-08-31

## المشكلة

التنقل في بوابة المالك يعيد شاشة الشعار «جاري تحميل القسم…» ويبقى معلّقاً (خصوصاً الاعتمادات وغيرها من أقسام التشغيل) لأن الطلب كان ينتظر Nest على Render Free، وإذا فشل/انتهت المهلة بقيت الواجهة بدون بيانات للأبد.

## الإصلاح

1. قراءة **الاعتمادات / الفواتير / المصروفات / الصيانة** (مع العقارات والأطراف) من **Neon** مباشرة.
2. عند توفر Neon: لا ننتظر `/v1/operations/context` ولا health لـ Nest إذا كانت البيانات جاهزة من القاعدة.
3. إذا Nest نائم وقسم بلا mapper: إرجاع قائمة فارغة فوراً بدل التعليق.
4. على العميل: مهلة رسم ~1.2 ثانية ثم عرض الكونسول (فارغ إن لزم) بدل سبينر لا نهائي.
5. تدفئة خاملة لأقسام Neon أولاً في الذاكرة.

## تحقق

حدّث بقوة → افتح بوابة المالك → تنقّل بين الاعتمادات / الفواتير / العقارات. يفترض ظهور القسم خلال ثانية أو ثانيتين دون شاشة تحميل طويلة.
