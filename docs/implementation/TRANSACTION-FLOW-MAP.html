قرارات العمل المعتمدة (1.1)

# الموضوع القرار
R1 إلغاء / فسخ الإيجار المستأجر يقدّم طلب إلغاء → الإدارة تعتمد ويُثبَّت تاريخ الإلغاء. الإدارة أيضاً تستطيع بدء الإلغاء. قبل ظهور «ملغي» للمستأجر: اعتماد المحاسب (لا متأخرات/مطالبات + تصفية فواتير الخدمة). بعدها يظهر للمستأجر ملغي.
R2 التأمين / الضمان في كل حالات الخروج (إنهاء أو فسخ/إلغاء) التأمين مرتبط بالمخالصة.
R3 التجديد ملحق موقّع ثم إلزاماً: جداول الشيكات + تصفية الفواتير + تأكيد المحاسب. التجاهل فقط باستثناء المدير.
R4 بيع ناجح نقل ملكية داخل النظام للمشتري؛ اسم المالك الجديد يظهر؛ أرشفة / تفعيل لاحقاً؛ المالك السابق يبقى في السجل كمالك سابق.
R5 بيع وحدة مؤجرة مسموح. تُنقل حقوق ملكية الإيجار إلى المالك الجديد دون إنهاء الإيجار أولاً.

حالات الإيجار

المرحلة الحالة المتوقعة المسؤول
حجز معلّق reservations.pending عمليات
عربون مؤكد confirmed + قيد reservation_deposit محاسب
قيد الإجراء leases.draft + اعتمادات/شيكات/توقيع محاسب / مالي / إدارة
ساري leases.active عمليات
طلب إلغاء طلب مستأجر أو إدارة + تاريخ إلغاء مستأجر / إدارة
بانتظار المحاسب قبل الإلغاء لا متأخرات · فواتير خدمة · مخالصة تأمين محاسب
ملغي (ظاهر للمستأجر) بعد اعتماد المحاسب نظام
تجديد ملحق → شيكات → فواتير → محاسب (أو استثناء مدير) عمليات + محاسب
شاغر مرة أخرى مهمة + صيانة + محاماة + مصروف تلقائي ثم متابعة

قواعد البيع

  • البيع لا يُمنع بسبب وجود إيجار ساري.
  • عند البيع والوحدة مؤجرة: تُنقل حقوق ملكية الإيجار إلى المالك الجديد؛ المستأجر يبقى على عقده ما لم يُلغَ بمسار الإلغاء المعتمد.
  • بعد closed_won: نقل ملكية داخل النظام + سجل تاريخي للملاك.

ج) حلقة حياة الوحدة

stateDiagram-v2
  [*] --> Vacant
  Vacant --> Leased: حجز→عربون→عقد→تفعيل
  Leased --> Leased: تجديد ملحق+شيكات+فواتير+محاسب
  Leased --> CancelPending: طلب إلغاء / إلغاء إدارة
  CancelPending --> AccountantGate: اعتماد إدارة + تاريخ
  AccountantGate --> Cancelled: لا متأخرات + فواتير + تأمين
  Cancelled --> Vacant: متابعة شغور
  Vacant --> Sold: closed_won + نقل ملكية
  Leased --> Sold: بيع مؤجّر + نقل حقوق الإيجار
  Sold --> Managed: مالك جديد نشط أو مؤرشف

د) فجوة التنفيذ مقابل القرار

القرار في الكود اليوم المطلوب لاحقاً
R1 end / terminate مباشر طلب → إدارة → محاسب → ثم ملغي للمستأجر
R2 مخالصة/مهمة شغور جزئياً ربط إلزامي بمخالصة التأمين قبل الإغلاق
R3 ملحق تجديد موقّع بوابة محاسب إلزامية + استثناء مدير
R4 صفقة بيع بلا نقل ملكية كامل نقل المالك + تاريخ ملاك سابقين
R5 غير مكتمل تحديث مالك العقد/الوحدة مع بقاء المستأجر
