# الإصدار 0.8.3 — تواريخ العقود ونوعها ونوع العقار، مع التصفية والبحث

**التاريخ:** 2026-10-12
**الصفحة:** قائمة العقود `/[locale]/{owner,developer}/contracts`

## المشكلة

- قائمة العقود كانت تعرض الأعمدة: الرقم، والإصدار (`initial`)، والحالة، والاعتماد، وتاريخي الإرسال والاكتمال.
- الوحدة كانت تظهر معرّفاً مقطوعاً بدل اسمها.
- لا تظهر تواريخ التوقيع والبداية والانتهاء، ولا نوع العقد (يومي أو شهري أو سنوي)، ولا نوع العقار (سكني أو تجاري أو زراعي أو صناعي).
- التصفية كانت بالحالة فقط.

## الحل

### 1. أعمدة القائمة

| العمود             | المصدر                                                     |
| ------------------ | ---------------------------------------------------------- |
| العقد              | رقم العقد                                                  |
| المستأجر / المشتري | اسم الطرف الثاني                                           |
| العقار والوحدة     | اسم العقار، وتحته الوحدة دون تكرار اسم العقار              |
| نوع العقد          | يومي، أو شهري، أو سنوي، أو بيع                             |
| نوع العقار         | سكني، أو تجاري، أو زراعي، أو صناعي                         |
| تاريخ التوقيع      | آخر توقيع إلكتروني اكتمل به العقد، وإلا وقت اكتماله        |
| تاريخ البداية      | من بيانات العقد، وإلا من عقد الإيجار المرتبط               |
| تاريخ الانتهاء     | من بيانات العقد، وإلا من عقد الإيجار المرتبط               |
| الحالة             | مسودة، أو مرسل، أو توقيع جزئي، أو موقّع، أو ملغى، أو مفسوخ |

نوع العقد ونوع العقار يظهران شارتين ملوّنتين. على الجوال تعرض كل بطاقة رقم العقد وكل الحقول، وزر «عرض العقد».

**كيف يُحدَّد نوع العقد:**

- **يومي:** عقود الإقامة القصيرة.
- **بيع:** عقود البيع.
- **سنوي:** عقد الإيجار الذي مدته سنة كاملة فأكثر.
- **شهري:** عقد الإيجار الأقصر من سنة.

**كيف يُحدَّد نوع العقار:**

- إن حُدّد الاستخدام في شروط عقد الإيجار (سكني أو تجاري) فهو المعتمد.
- وإلا فمن تصنيف العقار:
  - شقة أو فيلا أو مبنى ← سكني.
  - مكتب أو محل ← تجاري.
  - مستودع ← صناعي.
  - أرض ← زراعي.

### 2. التصفية والبحث

- **البحث:** برقم العقد، أو اسم المستأجر، أو اسم العقار، أو الوحدة.
- **مرشحات جديدة تحت شريط البحث:**
  - **نوع العقد:** يومي، أو شهري، أو سنوي، أو بيع.
  - **نوع العقار:** سكني، أو تجاري، أو زراعي، أو صناعي.
  - **السريان:**
    - ساري، أو لم يبدأ بعد، أو منتهٍ، بحسب تاريخ اليوم بتوقيت مسقط.
    - عقود البيع لا تدخل في هذا المرشح، لأنها بلا مدة.
  - **من تاريخ / إلى تاريخ:** تُظهر العقود التي تتقاطع مدتها مع الفترة المختارة.
- **مرشح الحالة:** باقٍ كما هو، وأُضيفت إليه حالتا «ملغى» و«مفسوخ».
- **زر «مسح التصفية»:** يظهر عند تفعيل أي مرشح، ويعيد القائمة كاملة.
- **عدد النتائج:** يتحدّث مباشرة مع كل تغيير.

### 3. إصلاحات مرافقة

- أيقونة البحث كانت تظهر رموزاً مشوّهة («âŒ•») بسبب خطأ في الترميز. صارت الأيقونة الصحيحة.
- تواريخ الجداول في لوحة التشغيل تُعرض الآن بتوقيت مسقط. والتواريخ المجرّدة (مثل البداية والانتهاء) لا تنزاح يوماً بحسب منطقة المتصفح الزمنية.

## التحقق

- **الفحوص:** فحص الأنواع ناجح، وESLint على الملفات الجديدة والمعدّلة دون أخطاء جديدة.
- **الاختبارات:**
  - 4 اختبارات جديدة لتحديد النوع والسريان، ومعها بقية الاختبارات ناجحة.
  - الإخفاقان المعروفان سابقاً لا علاقة لهما بهذا الإصدار.
- **الاستعلام الجديد:** شُغّل على قاعدة الإنتاج للقراءة فقط.
  - العقدان CTR-2026-000001 وCTR-2026-000002: يومي، سكني (مبنى النور، شقة A-01).
  - البداية والانتهاء: 9 → 11 أكتوبر للأول، و8 → 9 أكتوبر للثاني.
  - التوقيع: 11 أكتوبر للأول، و12 أكتوبر للثاني.
- **معاينة محلية بخمسة عقود** (يومي، وسنوي تجاري، وشهري قادم، وبيع زراعي):
  - كل مرشح أعطى العدد المتوقع، وكذلك مرشح الفترة والبحث بالاسم و«مسح التصفية».
  - المعاينة بالعربية والإنجليزية وبعرض الجوال.

## ملاحظات

- لا تغيير في قاعدة البيانات.
- لا يوجد في بيانات العقار حقل مستقل لنوع الاستخدام. لذلك يُستنتج النوع من شروط العقد أو تصنيف العقار:
  - الأرض تُعامل زراعية والمستودع صناعياً.
  - لتحديده يدوياً لكل عقار يلزم حقل جديد في قاعدة البيانات، أي ترحيل يحتاج موافقتك.
