# الإصدار 0.2.93 — إصلاح حفظ العقار (Neon أولاً)

**التاريخ:** 2026-08-31

## المشكلة

عند تعديل عقار (مثل إضافة المجالس/الصالات) ظهرت:
«تعذر حفظ العقار… DATABASE_URL…» مع زر إعادة الاتصال بـ Nest.

السبب الأرجح: الاعتماد على Nest لجلب CSRF و/أو مسار Nest-first قبل Neon، فيفشل الطلب عند بطء/انقطاع Render رغم أن `DATABASE_URL` مضبوط.

## الإصلاح

1. قراءة رمز CSRF من كوكي `bhd_r_csrf` مباشرة عند توفره (بدون Nest).
2. إنشاء/تحديث حزمة العقار عبر **Neon أولاً**، وNest احتياطياً فقط.
3. رسالة خطأ أوضح للمهلة/الشبكة.

## تحقق

افتح التعديل → احفظ بعد ضبط المجالس/الصالات → يفترض النجاح والبقاء أو الانتقال لصفحة العقار.
