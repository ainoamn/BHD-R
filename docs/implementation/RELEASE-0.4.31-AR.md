# الإصدار 0.4.31 — تنسيق الأسعار وصفحة الحجز وأنواع الإقامة

**التاريخ:** 2026-09-02  
**الإنتاج:** https://r.bhd-om.com

## الملخص

1. **تنسيق الأسعار**: المبالغ بدون فاصلة عشرية إلا إذا وُجد كسر حقيقي (مثل تخفيض 18.5).
2. **إصلاح تأكيد الحجز**: كان الحجز المؤقت يفشل بسبب تمرير `Date` خام إلى SQL، فتظهر «تعذّر إكمال الحجز. أعد المحاولة.»
3. **صفحة حجز مستقلة**: من صفحة الإقامة → «متابعة الحجز» تفتح `/stays/{slug}/book` بأسلوب قريب من Booking.com.
4. **أنواع الإقامة من الإعداد**:
   - إقامة مع مبيت
   - إقامة بدون مبيت
   - مبيت فقط

## قاعدة البيانات
