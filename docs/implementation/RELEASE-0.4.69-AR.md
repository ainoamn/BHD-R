# BHD R 0.4.69 — عرض كامل + تقويم أوضح

## المطلوب
جعل صفحات البوابة تملأ عرض الشاشة، وإصلاح تقويم الإشغال بحيث لا تتداخل نصوص الحجز داخل خلايا الأيام.

## ما تغيّر
- إزالة قيد `max-width: 64rem` عن محتوى البوابة (`.form-shell` / `.stays-portal` / `.ops-workspace`).
- توسيع `--container` للمحتوى العام إلى `100rem`.
- خلايا تقويم أكبر في وضع العمليات؛ عرض «محجوز / مؤقت / مغلق» فقط داخل الخلية.
- مرجع الحجز (`ST-…`) في `title` وقائمة الحجوزات أسفل التقويم بدل تراكب داخل الخلية.
- تسميات عربية أوضح لأنواع الأقفال في قائمة الحجوزات والإغلاقات.

## اختبار
- [ ] `/ar/owner/stays/calendar` يملأ عرض المنطقة الرئيسية بدون هوامش فارغة كبيرة.
- [ ] الأيام المحجوزة تظهر بلون واضح ونص قصير بدون تداخل.
- [ ] قائمة «الحجوزات والإغلاقات» تعرض المرجع والتواريخ بوضوح.
- [ ] صفحة العقارات/الحجوزات في البوابة أعرض من السابق.
