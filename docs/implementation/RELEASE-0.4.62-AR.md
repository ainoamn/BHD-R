# BHD R 0.4.62 — مسار التوقيع بعد الدفع

## المشكلة
بعد الدفع كان التحويل مباشرة إلى `/stays/booking/confirmed` لأن `STAY_ESIGN_REQUIRED` و`NEXT_PUBLIC_STAY_ESIGN_REQUIRED` كانا مضبوطين على `0` في Vercel.

## المطلوب
دفع → توقيع العقد → عرض العقد معتمد إلكترونياً من بن حمود → تفاصيل الحجز/التأكيد.

## ما تغيّر
1. تفعيل متغيرات التوقيع على Vercel (`1`).
2. بعد إكمال الدفع (sandbox) يُفرض `returnPath` إلى `/stays/booking/sign` عند تفعيل التوقيع.
3. صفحة التأكيد تعيد التوجيه إلى التوقيع إذا كان الدفع مكتملاً والعقد غير موقّع.
4. بعد إتمام التوقيع تظهر شاشة «العقد معتمد إلكترونياً من موقع بن حمود» ثم زر المتابعة إلى التأكيد.

## اختبار
- [ ] حجز جديد → دفع → صفحة التوقيع (وليس confirmed).
- [ ] توقيع + هوية + سيلفي → شارة الاعتماد → تفاصيل الحجز.
- [ ] فتح confirmed لحجز مدفوع بلا توقيع → يحوّل إلى sign.
- [ ] حجز `ST-0343C0F6`: افتح [صفحة التوقيع](https://r.bhd-om.com/ar/stays/booking/sign?ref=ST-0343C0F6) أو confirmed (سيحوّل).
