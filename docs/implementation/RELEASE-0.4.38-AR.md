# الإصدار 0.4.38 — كatalog إقامة يومية لكل وحدة + تصفية وطرق عرض

**التاريخ:** 2026-09-02  
**الإنتاج:** https://r.bhd-om.com

## الملخص

1. **وحدة لكل بطاقة:** `/ar/stays` يعرض كل وحدة منشورة على حدة (مثل `/ar/properties`) بدلاً من دمج وحدات المبنى في بطاقة واحدة.
2. **تصفية كاملة:** شريط جانبي بنفس أسلوب العقارات — ميزانية لليلة، مصفيات رائجة، مصفيات ذكية، نوع الوحدة، غرف/حمامات، موقع، مرافق، و«اعرض على الخريطة».
3. **طرق العرض:** قائمة · شبكة · جدول مع ترتيب (الأحدث، السعر، الغرف).
4. **رابط الوحدة:** كل بطاقة تفتح `/stays/{slug}?unit={unitId}` مع دعم معامل `unit` في صفحة التفاصيل.

## تحقق

- [ ] `/ar/stays` — مبنى النور يظهر كوحدات منفصلة (A-01, A-02, R-01…)
- [ ] التصفية الجانبية والخريطة تعمل
- [ ] التبديل بين قائمة / شبكة / جدول
- [ ] النقر على وحدة يفتح التفاصيل للوحدة الصحيحة
