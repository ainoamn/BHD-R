# الإصدار 0.4.32 — متابعة الرحلة + جرس تنبيهات الحجوزات

**التاريخ:** 2026-09-02  
**الإنتاج:** https://r.bhd-om.com

## الملخص

1. **إصلاح متابعة الرحلة**: بحث مرجع الحجز كان يمر عبر `/api/backend` فيرجع جسمًا فارغًا → «رد غير صالح من خادم الحجز». أصبح عبر Neon: `/api/public/stays/guest/lookup`.
2. **جرس في الهيدر**: يعرض الحجوزات الأخيرة وحالة الدفع/التنبيه، مع شارة للأفعال المطلوبة (مثل بانتظار الدفع).
3. **ربط الحجز بالحساب** عبر Neon: `/api/public/stays/guest/claim` و `/api/public/stays/guest/mine`.

## تحقق

- [ ] من صفحة التأكيد → «متابعة رحلتي» تظهر تفاصيل `ST-…` بلا خطأ
- [ ] جرس الهيدر يظهر الحجز وحالته
- [ ] ربط الحجز بحساب مسجّل يعمل
