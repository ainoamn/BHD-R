# تقرير التحقق النهائي — 2026-08-23

هذا التقرير يثبت حالة المصدر المسلّم للإصدار `0.1.0`. لا يمثل شهادة PCI أو SOC 2 أو ISO، ولا يدّعي انعدام الثغرات بنسبة 100%.

## بوابات الجودة الناجحة

- تثبيت الاعتماديات من `pnpm-lock.yaml` بوضع frozen.
- فحص regression لمنع الأسرار داخل المصدر والسجلات.
- Prettier وESLint عبر 13 حزمة و23 مهمة لكل من lint وTypeScript.
- Unit وBackend وFrontend وIntegration وE2E، بما فيها 3 اختبارات API تشغيلية و12 رحلة Playwright بالعربية والإنجليزية وعلى Chromium للهاتف وسطح المكتب.
- بناء إنتاجي ناجح لجميع الحزم وتوليد 40 صفحة Next.js.
- `pnpm audit --audit-level=low`: لا توجد ثغرات معروفة وقت التحقق.
- `drizzle-kit check`: مخطط الهجرات متسق.
- تنفيذ الهجرات مرتين على PostgreSQL 17/PostGIS لإثبات قابليتها للتكرار.
- 4 اختبارات قاعدة بيانات فعلية بحساب non-superuser لإثبات RLS ومنع الوصول بين الشركات وبين المستأجرين.
- بناء صور Docker الأربع: API وWeb وWorker وMigration.
- تشغيل API وWeb من الصور المصغّرة بوضع read-only: `live=200` و`ready=200` والصفحة العربية `200`، مع CSP وHSTS و`nosniff` وOpen Graph.

## أحجام صور الاختبار

| الصورة    | الحجم التقريبي |
| --------- | -------------- |
| Web       | 459MB          |
| API       | 480MB          |
| Migration | 353MB          |
| Worker    | 1.56GB         |

يضم Worker عمداً Chromium وخطوط Noto من أجل PDF عربي سليم. يعتمد البناء على cache مشترك لـpnpm، ويستخدم الويب Next.js standalone، بينما تحتوي الصور الأخرى على production dependencies فقط.

## أعمال لا يمكن تنفيذها من المصدر وحده

- تسجيل عميل BHD Identity الحقيقي وتعيين redirect URIs وJWKS وسياسات الحسابات.
- تدوير مفاتيح الدفع والتشفير والجلسات الحقيقية أو حذف سجلات من قاعدة الإنتاج.
- ضبط DNS/TLS وVercel/Render/Neon وRedis وS3 وSentry والبريد والنسخ الاحتياطية دون صلاحيات البيئات.
- اعتماد النصوص القانونية النهائية أو إصدار شهادات PCI/SOC 2/ISO.
- إجراء اختبار اختراق كامل للإنتاج من دون تفويض مكتوب وبيئة وحسابات اختبار متعددة.
