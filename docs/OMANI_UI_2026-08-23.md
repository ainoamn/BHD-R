## السلوك الوظيفي

1. الزائر يرى هوية عُمانية واضحة في أول إطار (العلامة، الصورة، CTA واحد واضح).
2. الدخول الأساسي يوجّه إلى BHD Identity عبر `/v1/auth/oidc/start` (مع احتياطي Next عند غياب API عام).
3. بعد الجلسة يظهر مبدّل التطبيقات وروابط الحساب ضمن منظومة BHD.
4. العربية RTL والإنجليزية LTR مدعومتان بالكامل.
5. الصور عبر `next/image` وصيغة WebP لتقليل الوزن.
