# نموذج تهديد — الإقامات اليومية (BHD R Stays)

إضافة إلى [`docs/THREAT_MODEL.md`](../../THREAT_MODEL.md). لا يستبدل النموذج العام.

**التاريخ:** 2026-08-31 · **المرحلة:** 0 (تثبيت)

## أصول إضافية

- تقويم الوحدة وأسعار الليالي والعروض.
- Hold مؤقت وQuote المثبت السعر.
- بيانات الضيف ووثائق الهوية.
- Folio الإقامة والمدفوعات والاسترداد.
- تعليمات الدخول والعنوان الدقيق بعد التأكيد.
- ربط iCal/OTA لاحقاً (SSRF).

## مهاجمون إضافيون

- زائر يحاول حجزاً مزدوجاً أو تعديل سعر في المتصفح.
- ضيف يحاول رؤية حجوزات ضيف آخر.
- مالك مؤسسة أخرى (IDOR عبر UUID).
- مزوّر webhook دفع أو إعادة حدث.
- مستأجر طويل المدة يُمنح صلاحيات إقامة يومية بالخطأ (والعكس).
- مستورد تقويم خارجي يوجّه الطلبات لشبكة داخلية.

## STRIDE — إضافات Stays

| الفئة | سيناريو | التخفيف (إلزامي في المراحل اللاحقة) |
| ----- | ------- | ------------------------------------- |
| Spoofing | جلسة ضيف مسروقة تفتح قسيمة/تعليمات وصول | cookies آمنة، صلاحية `guest` منفصلة، تقليل الحقول العامة |
| Tampering | تغيير مبلغ Quote بعد الدفع | Quote immutable؛ مطابقة مبلغ/عملة في webhook؛ Decimal |
| Tampering | تداخل حجزين لنفس الوحدة | `daterange` + GiST exclusion + معاملة قفل |
| Repudiation | إنكار موافقة شروط أو إلغاء | audit append-only؛ Idempotency-Key؛ سجل حالات |
| Information disclosure | رقم وحدة / مالك / إحداثيات دقيقة قبل التأكيد | إسقاط عام محدود؛ 404 عبر المؤسسات |
| Denial of service | بحث تواريخ واسع أو Hold spam | rate limits؛ انتهاء Hold؛ تنظيف holds قبل الفحص |
| Elevation of privilege | مستأجر طويل → إدارة تقويم يومي | صلاحيات `stay.*` مركزية؛ Flag + RLS |

## مسارات إساءة ذات أولوية

1. **Race على Hold/Booking:** 50 طلباً متزامناً → فائز واحد فقط (اختبار قبول مرحلة 1).
2. **Payment replay:** `external_event_id` فريد؛ لا يكرر تأكيد الحجز.
3. **Cross-tenant profile/booking read:** مفتاح `(organization_id, id)` + RLS.
4. **SSRF عبر iCal (مرحلة 8):** allowlist/DNS/منع private؛ يُحظر حتى تُنفَّذ الضوابط.
5. **خلط بوابة المستأجر مع الضيف:** سياقات منفصلة في مبدّل البوابات.

## Feature Flag كسيطرة أمنية مؤقتة

طالما `STAYS_*` مغلقة: لا مسارات عامة `/stays`، لا APIs كتابة stays ظاهرة، لا جداول سلوكية مفعّلة في الواجهة. هذا يقلل سطح الهجوم أثناء البناء (Expand).
