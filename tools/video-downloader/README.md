# أداة تنزيل الفيديو

أداة محلية بواجهة عربية تعمل على Windows باستخدام Python 3 وTkinter. تنزيل الملفات المباشرة لا يحتاج إلى حزم إضافية. دعم HLS يستخدم FFmpeg الاختياري، المثبت على هذا الجهاز.

1. افتح `start.cmd` بالنقر المزدوج، أو نفّذ `python downloader.py` من هذا المجلد.
2. ألصق رابط ملف الفيديو المباشر واختر مكان الحفظ.
3. اضغط **تنزيل / استكمال**. يمكنك الإيقاف المؤقت والعودة إلى الرابط ومكان الحفظ نفسيهما.

تعرض الأداة الحجم والسرعة ونسبة الإنجاز عندما يعلن المصدر حجم الملف. تحفظ الجزء الجاري في `.part` حتى يكتمل التنزيل، ولا تستبدل ملفاً موجوداً. تدعم استكمال المصادر التي توفر Range وETag أو Last-Modified؛ وإلا تبدأ من جديد لضمان عدم دمج أجزاء من ملفات مختلفة. عند انقطاع الإنترنت، أعد المحاولة يدوياً. لا تحذف ملفي `.part` و`.part.json` إذا أردت الاستكمال.

تعمل الروابط الموقعة خلال مدة صلاحيتها إذا كان المصدر يسمح بتنزيلها مباشرة. تدعم قوائم HLS (`m3u8`)، ومنها AES-128 عندما يوفر المصدر مفتاح التشغيل بالطريقة المعتادة، وتحفظها في حاوية MP4 دون إعادة ضغط. لا تدعم تجاوز DRM أو تسجيل الدخول أو قيود الوصول، ولا تدعم DASH (`mpd`). روابط صفحات المشاهدة ليست روابط ملفات مباشرة.

تنزيل HLS يعرض الحجم والسرعة دون نسبة مئوية، ويبدأ من جديد بعد الإيقاف أو الفشل. ملفه المؤقت ينتهي بـ `.hls.part.mp4`؛ لا تشغله قبل اكتمال العملية. استكمال الملفات المباشرة يعمل كما هو موضح أعلاه. لنقل دعم HLS إلى جهاز آخر، ثبّت المكوّن الاختياري من PowerShell:

```powershell
python -m pip install --target "$env:LOCALAPPDATA\DirectVideoDownloader\runtime" imageio-ffmpeg==0.8.0
```

يُرسل الرابط إلى مصدره لتنزيل الملف، ولا توجد خدمة وسيطة. لا تُحفظ قيمة الرابط في بيانات الاستكمال؛ يُحفظ ملخص SHA-256 ومعرّف نسخة الملف فقط. إذا تغير الرابط الموقّع، قد يبدأ التنزيل من جديد. اختر مجلداً محلياً يدعم الروابط الصلبة (مثل NTFS).

لتشغيل اختبارات التنزيل المحلية: `python -m unittest -v`. اختبار HLS ينشئ بثاً مشفراً محلياً ويتحقق من تنزيله وفك ترميزه، ويُتجاوز إذا لم يُثبت FFmpeg.
